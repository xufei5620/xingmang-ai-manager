## 用户

- 新装或更新 Codex 默认装 0.160.1：Windows 上不再一闪一闪冒出黑色窗口，断线重连后没发出去的话也会接着发，不会重复发两遍。
- 新装或更新 Grok 默认装 1.0.46，跟上官方最新的稳定版；画图、起标题照旧走当前账号。
