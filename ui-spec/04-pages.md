## 新增：视频剪辑（2026-10-25）

位于侧栏工作组、画布之后，T1 普通内容页；v4 原型没有这一页，照 T1 的卡片写法摆。历史账号登录时侧栏和顶部搜索都不出这一项（历史账号没有视频模型）；没登录时页里只有空状态「登录后才能用」（生成视频用的是星芒账号的额度，先登录）和「登录」。顶部搜索认「视频」「剪视频」「剪辑」「生成视频」「一句话出片」「分镜」「短视频」「拼视频」「字幕」。

页头「视频剪辑」，说明「说一句想拍什么，AI 写好分镜、一段一段生成，再在这台电脑上拼成一条带字幕的视频。」；有内容后右边「重新开始」（先确认，生成过的片段和拼好的成片还在 AI 作品文件夹里）。

1. 「想法」卡：「想拍什么」（最多 2000 字）；「画面」（竖屏 9:16 / 横屏 16:9 / 方形 1:1）、「镜头数」（1–12）、「每段时长」（只列出视频模型能出的长度，换模型时挪到最近的一档）、「烧字幕」开关；「写分镜」「出视频」两个模型菜单跟聊天的一样按厂商分节，模型下面小字「{分组}分组」，底部「刷新模型」。「写分镜」按钮（已有分镜时叫「重新写分镜」，有片段时先确认会换掉现在的镜头），写的时候换成「停止」，旁边「AI 正在写分镜…」。下面一句「写分镜按文字模型的用量计费；之后每生成一段视频单独计费。」
2. 分镜卡：标题是 AI 起的片名，旁边「N 个镜头 · 每段 S 秒 · 共约 T 秒」。每个镜头一行：左边缩略图（生成好以后点了用电脑的播放器打开，页面里不放视频），「第 N 个镜头 · 画面」「字幕」（关了烧字幕就不出），右边状态小标签（还没生成 / 排队中 / 生成中 x% / 排队较久 / 正在下载 / 正在保存 / 已生成 / 没生成出来，没生成出来时描述下面一行红字原因）和生成 / 重新生成、上移、下移、删掉（有片段时先确认）。最多 12 个镜头，底下「加一个镜头」。右上「生成全部 N 段」/「生成剩下的 N 段」，点了先确认：「用「{模型}」生成 N 段、每段 S 秒，每段单独计费。」「一段要几分钟。中途停下的话，已经交给服务端的那几段照样生成、照样扣费。」；重新生成写「会再扣一次费，新片段生成好以后换掉现在这一段；旧的那段还在 AI 作品文件夹里。」。同时最多 3 段在生成，生成中右上换成「停止生成」，停下后提示几段已经交给服务端、照样扣费、好了存进 AI 作品文件夹、这里不会自动换上。
3. 「拼成一条视频」卡：「清晰度」（480p / 720p / 1080p）、「画面对不上时」（裁边铺满 / 补黑边）、「拼成一条视频」（片段没齐时灰着，旁边写「还有 N 个镜头没生成片段。」或「等片段都生成好再拼。」；正在写分镜时也灰着，写「等分镜写完再拼。」；齐了写「在这台电脑上拼，不花钱。」。拼的时候分镜、字幕和画面设置都锁着，万一拼完时对不上，成片照样存进作品库，提示「成片已经存进 AI 作品文件夹。拼的时候分镜改过了，这里没有换上，要用新的分镜就再拼一次。」）；拼的时候进度条（正在读取第 i / n 段、正在拼接画面、正在写入文件、正在存进 AI 作品文件夹）和「停止」。拼好一行成片：缩略图、片名、时长和尺寸、「用播放器打开」「另存为」，成片存进 AI 作品文件夹。

工程（想法、设置、分镜、片段和成片的编号）按账号存在本机，下次打开照旧；正在生成的不记，回来是「还没生成」。余额不够、额度上限的报错条带「去充值」/「去调额度」。

## 3. 首页与工具配置

首页保留工具列表和右侧环境/账号摘要。工具行依次解释工具、版本、来源、当前状态、主动作和更多；用户不需要先理解所有运行时名词。

工具状态拆开：安装、配置来源、官方登录、星芒 Key、运行、可更新、安装任务。主动作按阻塞条件显示安装、准备环境、连接账号、查看密钥、打开、重试或取消，不让一个 configured 布尔掩盖所有状态。

配置弹窗只管点开的那一个工具，没有工具页签（v4，2026-10-15 批05）：标题「{工具} 配置」，Codex 两个入口共用一份配置，副标题写明这一点；官方模型在 Codex 窗口内选择。上面三张来源卡横排：当前账号（推荐）、官方账号（ChatGPT / Claude，Grok 没有）、自己填写密钥。选当前账号是「访问密钥」下拉（保持当前、自动准备、账号里的每把密钥，第二行写掩码和分组），旁边「刷新密钥」「管理密钥」；自己填写是「星芒密钥」框（星芒站按 sk- 开头、20 位以上拦）；官方账号是一块登录状态，Codex 读得出邮箱时给「查看 ChatGPT 账号额度」，点了关掉配置、换成额度弹窗。下面是默认模型和「检测模型」（检测过写「这把密钥能用 N 个模型」）、打开工具时进入的文件夹；Codex 桌面端多一块折叠「界面语言与文件夹权限」（展开时读一次，不再有「检查中文界面」），最后折叠「高级」：配置文件位置（可复制）、打开配置文件夹、查看配置备份、保存摘要和「重置为初始状态」。

来源必须区分星芒账号、自己填写的星芒密钥、官方身份、已有第三方配置。官方身份按 Provider 为 ChatGPT/Claude/Google，Grok 不提供官方登录选项。unknown 显示解释和处理入口，不自动当作星芒配置覆盖。

底栏左边一行「只改账号、密钥和模型，改之前会自动备份。」，右边「取消」和主按钮：没改动时是「完成」，点了只关上；还没检测过的是「保存并检测」，先列出模型、选中的能用就接着保存；其余「保存配置」。保存只合并目标字段；重置在「高级」里原处再确认一次，先备份再整份重新生成。保存失败留在弹窗里；成功就关掉，右下角说「{工具}的配置已保存」（重置、换成官方账号各有一句）。有没保存的修改时，关闭先亮底部离开条。配置保存成功与重启失败是两个结果，不能回写成配置未保存。

命令行工具卡片「…」最上面是「接着之前的对话…」（这个工具聊过才有）、「选择其他文件夹…」「新建项目文件夹并打开」（2026-10-16）。以前最上面列的是最近几个文件夹的整条路径，点了在那里开新对话，客户看着像对话记录；v4 原型那里本来也没有。「接着之前的对话…」打开一个 640 宽的弹窗，标题「接着 {工具} 之前的对话」，一个项目文件夹一行（对话开头那句、文件夹名、时间、「接着聊」），只放那个文件夹最近的一条（「接着聊」只接得上它），最多 8 行，文件夹没了的那行写「文件夹已不存在」、按钮灰着；底部左边「全部记录」去记录页，右边「开新对话」同卡片上的「打开」。「打开」本身不弹窗，一点就开。

Codex 卡片「…」里的「换用别家模型…」是单独一个小弹窗：只列当前账号这把密钥能用的别家模型（Codex 默认的放第一个），用 ChatGPT 账号时先一键「改用当前账号并保存」。外接工具（Claude Desktop、WorkBuddy、OpenCode）的弹窗同一个样子：没连好叫「连接 {名称}」、连好了叫「{名称} 配置」，名称旁写版本，访问密钥下拉、默认模型和「保存并检测」，连好了右下角说下一步。

## 5. 聊天与记录

## 6. 画布

45-canvas保留独立窗口外壳、项目栏、左节点库、中央点阵图/连线、右侧参数与底部运行状态。入口展示入门示例、最近项目、新建和导入；编辑区有所有项目、保存、运行/停止、连接、撤销、缩放/适应画布与导出。项目只保留在本次演示状态中，保存文案为“已保存到本次演示”。

| 节点type / 名称 | 字段与作用 |
|---|---|
| text / 文本输入 | 通用id/name/x/y与text，填写画面描述 |
| model / 模型处理 | model、instruction，选择示例文字/创意模型与处理说明 |
| image / 图片示例 | size、style，1024×1024、1536×1024、1024×1536参数与主题 |
| result / 查看结果 | 通用字段，运行完成后查看本地构图和输入描述 |

图数据为project.id/name/nodes/edges/updated，edge为起点/终点ID对；selected与参数同步。节点可添加、拖动标题、方向按钮/方向键20px移动、编辑、确认删除；删除清理关联边，撤销恢复节点和连接，保留最近30份编辑快照。画布缩放0.35–1.5独立于主窗口倍率。

连接通过起点/终点选择或点选后继节点建立；缺端点、自连、重复边、循环、结果节点输出或连接到文本节点均给出说明。运行前校验空图、文本/结果节点缺失、空名称/文本、未选模型、未连接输入/后继；错误列表可定位节点。

save.phase为saved/dirty/saving/failed；run.phase为idle/invalid/running/stopped/failed/done。保存和运行时锁定相关编辑，失败保留项目和输入并可重试。回调绑定S实例、canvas45对象、窗口打开状态和操作ID；停止/离开使旧任务失效。运行结果为CSS本地构图，不调用AI、不生成图片文件；size/style仅展示参数，不能声称输出了对应分辨率文件。

离开项目/回所有项目/新建/关闭共用canvasNavigate：运行中先选择继续运行或停止并继续，再处理未保存修改；未保存时可取消、放弃修改或保存并继续。保存失败留在当前图与确认中。A.canvasHasPending()提供dirty或保存/运行中的保护条件；A.canvasCloseThen(callback)在画布保护完成后继续主窗口操作，取消清除callback，S已变化时不执行旧回调。直接关闭画布本身不关闭主窗口。

导出下载format=xingmang-canvas-demo、version=1、project含name/nodes/edges的JSON，不等于真实工程保存。导入粘贴该结构或填入内置示例，新建项目而非覆盖原项目；校验名称、节点类型/ID/坐标/字段、数量及重复/无效/循环连接。格式错误保留文本。

键盘按系统使用Ctrl/⌘ S保存、Ctrl/⌘ Enter运行、Ctrl/⌘ Z撤销、Ctrl/⌘ W关闭。非输入上下文Delete/Backspace请求删除，聚焦节点方向键移动；中文组合输入不触发快捷动作，文本编辑保留原生撤销。Esc先关当前弹窗，再退出连接模式，再遵守关闭保护；弹窗内Tab循环。动作与场景见15，验收CV01–CV05，结果统一见16。

行状态区分已启用、停用、未授权、授权中、已授权、已过期、只读。OAuth 登录/退出有返回和失败重试；切工具不把上一工具连接带到下一个。启停/编辑/删除/更新按 capability 门控，失败回退到已确认值，保留草稿。

## 11. 设置八项单面板

未登录时也能在线路设置自救：登录、注册、找回密码的表单提供「切换连接线路」，在同一个 Dialog 内展示设置页同款线路面板；关闭面板返回原表单，保留已输入的账号、密码和验证码。保存失败保留确认值，保存期间不允许离开面板；仅手动点击「现在重开」才进入原生重启检查，取消重启继续保留表单。首次向导的「登录账号」也能到达此入口。

网络加速的「连接线路」小标题下有「星芒账号线路」和「历史账号线路」两行，各是一排三颗分段按钮「自动（推荐）/ 只用线路1 / 只用线路2」（v4 起，原来是 Select）；保存失败保留原值，保存中整排按钮点不了，保存成功只表示下次启动采用。已保存值与主进程本次启动值不一致时，卡片上面一条「线路已保存，等待重启」带「现在重开」，切换分页后仍保留；点「现在重开」先问「现在重开星芒？」（「稍后」/「现在重开」，正文提醒先保存工具里的工作；登录框里那份说没填完的登录信息要重新填），确认后才进入原生重启检查，重开继续经过已有未保存工作和运行任务保护。切换线路不切换账号，不跨站点共享凭据。

v4 起八组：外观显示、启动关闭、工具管理、网络加速、消息通知、备份迁移、隐私数据、版本更新（「账号」组去掉：切换账号、退出登录在个人中心账号概览，记住密码在账号安全）。左栏顶上「搜索设置」，下面每组一个图标加组名；「版本更新」有新版本、「网络加速」正在加速时组名后面带一个点（悬停写「有新版本」「加速中」）。左侧二级导航一次只渲染选中项的内容，不把八组堆成滚动长页；右侧内容长时只有右侧滚，左侧组名停在原处。左栏搜索有字时右边换成「搜索「…」」和「找到 {n} 项，可以直接在这里修改」，搜到的每一行上面带组名链接（点了清掉搜索、回到那一组），行本身照常能改；几个字都对上才算搜到（标题、常用说法、组名、小标题），搜不到写「没有找到相关设置」和「换个说法试试，比如「托盘」「镜像」「快捷键」。」。外观显示第一行是三张主题小预览卡（跟随系统 / 浅色 / 深色，没有系统桥时只有后两张），下面「文字与缩放」「辅助与显示」两个小标题，最后一行「恢复默认外观」（主题回跟随系统、关高对比度，缩放、大字、减少动画回到默认；显卡加速不动）。

每一行的 id、标题和常用说法登记在 `registry/business.ts` 的 `settingsItems`：设置页的行标题和顶部搜索读同一份，每行带 `data-anchor` 供搜索直达。2026-10-04 起：「启动时检查新版本」「自动更新」挪到「更新与关于」（「更新」页也能直接开关，改的是同一份设置）；「通知」里九个分类放在小标题「提醒哪些事」下，总开关关着时标题旁说明「桌面通知关着，下面这些都不会提醒」；「账号」新增「切换账号」；「网络」新增「企业证书」（去检查页并翻到「安全证书」那一项）。2026-10-15（v4 批08）起：一组里分几张卡由 `settingsSections` 和每行的 `section` 决定（`buildSettingsBlocks`），页内搜索用 `searchSettingsItems`，和顶部搜索读的是同一份标题和说法。

2026-10-16（v4 批09）起：游戏加速、工具配置备份、版本卡三项是整张卡（`settingsItems` 里带 `card: true`），各占一块、不和别的行挤进同一张卡；外面一层 `data-anchor` 给顶部搜索翻过去，落到时整张卡外围一圈再退掉。页内搜索搜到它们时也是整张卡，上面带组名链接。

2026-10-25 起：「工具管理」最下面加一张整卡「手机遥控 Codex」（`settingsItems` 的 `codex-remote`，v4 原型没有，照同组整卡的写法摆）：卡头右边只在有渠道开着时写「Codex 空闲 / 正在处理 / 等你同意 N 条」；一段说明；「干活的文件夹」一行（「选择文件夹」/「换一个」，路径主目录写 `~`）；下面每个渠道一块：标题、状态小标签（没打开 / 正在连接 / 已连上 / 要重新登录 / 出错了，不是已连上时下面一行灰字写原因）、填凭据、「打开遥控」开关（还差哪一步说明里就写哪一步）、配对码（大号等宽 6 位数字加「取消」）或「绑定的人」（「开始配对」/「换人」/「解绑」）。飞书那块没填凭据时是 App ID、App Secret 两个框和折起来的「怎么建飞书机器人」六步（只写字不放链接），填过了只写「App ID：…」和「重新填写」「清除」。微信那块标「实验功能」：最上面一条黄色提醒（这条通道是腾讯给 OpenClaw 开的，随时可能断），一行「微信扫码登录」/「已登录：ClawBot 末四位」加「扫码登录」/「重新扫码」；扫码弹窗里是二维码和一句怎么扫，扫完写「已扫码，请在手机上点确认」，手机上要输数字时换成输入框和「确认」，失败了给「重新扫码」「关闭」；退出登录用渠道标题行右边共用的那颗。星芒以管理员身份运行时卡上一条黄色提示、所有按钮灰着；凭据只能记到这次关掉时一条灰色提示。操作成功不弹小提示，失败在卡里出红条。

外观可立即预览；其他逐项保存：正在存时组名右边写「正在保存更改…」，存好了弹会自己消失的小提示（字照旧，如「已保存」「通知偏好已保存」），页面不往下跳；没存上照旧在页顶出红条；带「打开所在位置」的导出结果照旧在页顶。要先读系统状态的行，读的时候开关灰着不写字，没读到写「暂未读到」并在红条右边给「重新读取」，只有这台电脑真的不支持才写「此版本暂不支持」。开关失败回退已确认值，文本失败保留待重试草稿。不同字段独立保存，同一字段最新写入获胜；新账号/页面不得接收旧操作成功提示。系统设置显示生效范围，原生权限和重启条件由真实适配结果决定。

数据迁移/回滚保留前后快照；回滚不删新版数据。导出/清除说明范围、敏感信息与后果；原型的示例清单或确认预览不能当作真实完整导出/清除完成。
