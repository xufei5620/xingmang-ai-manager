## 开发

- 随包 Codex 型号名单换成 `rust-v0.170.0`（提交 `29eb79e9`，sha256 `d50b6749…3068`，与 `rust-v0.169.1` 逐字相同）：多了 `gpt-6.2-sol`、`gpt-6.2-astra`（官方标的最低客户端版本 0.166.0），别的型号只改提示词、说明、排序，`gpt-6.1-sol` 的 `context_window` 272000 → 500000；`openai_models.rs`、`LICENSE`、`NOTICE` 不变。Codex 推荐版本 0.169.0 → 0.170.0。用户那一条并进 `cli-verified-2026-11-09.md`（更新页 60 条已满）。依据写进 `docs/CLI-VERIFIED-VERSIONS.md`。
- `codex-model-catalog.ts` / `config-save-service.ts`：型号名单不再因为一个型号要的版本高过本机命令行就整份收回（以前账号一开 GPT-6.2，0.166 以下的命令行连 GPT-6.1 Sol 都跟着从菜单里消失，桌面端也一起丢）。改成照 OpenAI 自己的办法逐个型号筛：客户端版本按整版比（`client_version_to_whole`，0.167.0-alpha.3.2 算 0.167.0），命令行或桌面端用不了的型号先不写，其余照写；默认型号被筛掉、或剩下的全是菜单里不显示的，才和以前一样不写。整份收回只剩读不进的情形：命令行早于 0.147.0、桌面端早于 26.917 那批。桌面端自带的 Codex 版本按批次查新表 `codexDesktopBundledCliVersions`（26.917 / 26.930 / 26.1103 / 26.1111 四行，后两行 2026-11-18 读安装包里的 codex 核过），没记的新批次按上一行算，只会少列不会多列。本机守卫（装完、打开前、开机）看到名单里有本机 Codex 用不了的型号，照旧先收回那一行，下一次按账号核对再按新版本重挑。
