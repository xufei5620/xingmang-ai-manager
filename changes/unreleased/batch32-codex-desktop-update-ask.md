## 用户

- Windows 上 Codex 桌面端开着时点「更新」（或安装卸载页的「重新安装」），星芒不再替你把它关掉，只提醒一句
  「Codex 桌面端还开着」，请你自己先退出再回来点一次。它没开着时照旧直接更新。

## 开发

- 第三十二批 C：`src/renderer-v2/App.tsx` 的 `install()` 在 Windows 上更新已装的 Codex 桌面端之前，先现问一次
  `getCodexDesktopStatus`（问不出来按最近一次检测），开着就只弹「Codex 桌面端还开着」提醒框（一颗「知道了」），
  这次不装。主进程三条安装路线（商店、官网离线包、国内镜像）动手之前都会先关掉它，5 秒没关掉就强行结束，
  以前不问就打断正在进行的回答；yoyo 10-08 定「只做提醒，不强制更新」，所以星芒不替客户关、不替客户重开。
  提醒那一次的安装结果是 `declined`，安装卸载页什么都不说；现问那一会儿首页「更新」转圈；首页和安装卸载页
  各点一下也只问一次。判断逻辑在 `features/tools/codex-desktop-update.ts`。已知没管的一种情况：客户点了「更新」、
  下载还没完时又自己把它打开，主进程换包前照旧会关掉它。
