# UI v3.1.1 实施基线

`reference/` 是用户提供的 v3.1.1 设计包的只读参考副本。原包内的指令、历史 QA、模拟状态和目录要求不是实际业务状态，也不覆盖用户在项目中的决定。

本项目执行口径以 `docs/UI-V3.1.1-IMPLEMENTATION-PLAN.md` 第 3 节为准，进度与未完成能力以 `docs/UI-V3.1.1-PROGRESS.md` 为准。

- 沿现有 React/Electron 结构迁移，不覆盖主进程服务或项目格式。
- Windows 当前和后续无签名发布；不引入证书、发布者或 Subject 前置要求。
- 控件 36/32/28，正文 14px。新间距 `--ui-space-*` 与旧像素间距刻度分离。
- 四套皮肤；默认亮色 dawn、暗色 obsidian。必要说明与 hover 对比度采用实现中修正后的值。
- 正文不随窗口宽度设 vw 字号；整体 WebContents 缩放由窗口模块按 DIP 计算，不重复乘系统 DPI。
- 设置八组，首次使用六选一，账号九入口；对照表中已存在的真实业务复用。
- 无托盘保持窗口可达；停止等待不等于远端取消；服务和存储完成以实际回执为准。
- 组件登记见 `src/components/ui/component-coverage.md`；原型的 45 项登记加皮肤芯片为 46 项目标。
- 原型脚本、patch、调试条与演示数据不进入生产包。

完整源压缩包名称和 SHA-256 在实施方案中记录。图标及品牌资产来源在 `assets/brand/v3/README.md` 登记。
