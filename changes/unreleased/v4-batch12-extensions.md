- UI v4 批12 扩展和精选（`pages-management.tsx`、新 `pages-featured.tsx`、新 `extensions.css`）：外接工具、技能、插件三页
  换成同一套结构：工具页签（`Tabs` 的选项加 `leading` / `meta`，放工具标志和已装数量，没装写「未安装」）、「{工具} 官方叫

  顺序挨个调现有的 `addMcpServer`，中途失败只留没加上的工具。没有新 IPC。
