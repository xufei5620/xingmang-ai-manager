# 06 · 文案、状态与数值 v3.0

面向第一次使用 AI 工具的用户，先解释任务，再补真实术语。按钮写动作和对象，错误写影响和下一步。术语只在它帮助选择时出现，不把模块名、场景ID或实现细节放进产品流程。

## 1. 语义词典

| 内部概念 | 首次解释 / 持续用词 |
|---|---|
| Provider | 工具 / 工具归属，必要时显示真实工具名 |
| API Key | 访问密钥（Key）：让工具使用你的星芒额度；后续可简称密钥 |
| Account source | 账号来源：星芒账号、官方账号或自己填写的密钥 |
| unknown source | 已有第三方配置；先确认来源，不自动覆盖 |
| Codex Desktop | Codex 桌面端；图形界面，新手开始方式 |
| Codex CLI | Codex 命令行工具；需要终端时再解释 CLI |
| Node.js/npm | 命令行工具需要的运行环境；桌面端可独立使用时标“可选” |
| MCP | 外接工具（MCP）：让 AI 连接其他工具或数据 |
| Skill | 技能：为某类任务提供方法与步骤 |
| Plugin | 插件：一组扩展能力，按工具与范围管理 |
| scope | 安装范围：我的（全局）/当前工作区/当前仓库/系统内置 |
| merge/reset | 保留其他设置 / 使用初始配置 |
| subscription | 订阅额度，与账户余额分别显示 |
| capability | 不向用户显示该词；具体写“当前只读”“此工具不支持归档”等 |
| retry/recover | 重试是重新执行；恢复是把对象恢复到明确状态，不混用 |
| quote/order | 支付报价 / 订单；报价未下单，不显示“等待付款” |

“配置已保存”“工具已打开”“已到账”各自只表示对应结果。不要用“已完成”掩盖未安装、未连接、未重启或待核实。

## 2. 动作名称

同一动作保持同名：安装、重新检测、打开、连接账号、保存配置、返回修改、继续编辑、放弃修改、查询到账状态、重新获取报价、清空筛选、重新加载、去处理、返回检查。

加载保留动作名称，可附“正在保存/查询”；不用“操作中…”替代所有动作。危险确认直接说对象：“停用〈Key名〉？”“删除这份备份？”；主按钮对应“确认停用/删除备份”，次动作“保留/继续编辑”。

首次无数据：原因 + 第一件事；筛选无结果：改关键词/清空筛选；读取失败：已有数据保留 + 重新加载。不能把失败写成“暂无内容”。

## 3. 账号与工具状态

| 状态 | 用语 |
|---|---|
| Key active / disabled / expired / exhausted | 启用 / 已停用 / 已过期 / 额度用尽 |
| 未安装 | 未安装；主动作安装或查看安装步骤 |
| 安装中 / 取消中 | 显示当前阶段，取消时写“正在停止” |
| official未登录 | 请在官方工具中登录，再回来检查 |
| official读取额度失败 | 额度暂时没有读取成功；不据此说账号失效 |
| unknown | 发现已有配置，先确认账号来源 |
| 配置成功但重启失败 | 配置已保存，工具尚未重新打开；提供重新打开 |
| 切换部分同步 | 账号已切换，列明哪些工具尚未同步 |
| 无托盘 | 当前会话没有系统托盘，已保留窗口 |
| 系统通知受限 | 系统通知暂不可用，仍可在应用内查看结果 |

品牌词“星芒 AI”、Codex、Claude Code、Gemini CLI、Grok CLI 保持一致。真实技术名称不随意翻译；模型/版本为数据，示例名不代表可用性承诺。

## 4. 金额、额度与统计

账户余额、订阅、Key额度使用 USD，首次标题写“账户余额（美元 USD）”。日常金额显示 $12.40；细粒度调用费用保留4位，绝对值小于0.0001的非零费用可保留6位。未知为“—/暂未获取”，不写$0.00。金额计算按真实精度与服务返回，禁止对演示格式化函数反推账务精度。

支付确认同列报价币种、实付金额、到账USD或订阅权益、折扣、渠道、有效期；不把不同币种相加，也不靠客户端猜汇率。数字右对齐，值与单位一起显示。实际币种以服务端报价为准，本轮渠道示例不固定产品渠道名单。

图表写明范围与口径：消费/调用趋势、模型占比与排行；本轮看板RPM/TPM是所选范围内每分钟平均，不能叫瞬时/峰值。成功率说明分子分母，缺少缓存/首字延迟数据用“—”，不编造零值。

## 5. 时间、路径与敏感信息

界面采用当前用户本地日期/时间，详情可显示明确时区与完整时间。剩余时长、重置窗口、续期、Key到期、报价到期是不同概念，不能共用“快到期”。列表可用刚刚/昨天，详情提供完整时间。

路径/命令/ID使用等宽字体，长路径可选中或展开；报告将个人路径用户名替换为~等脱敏值。Key、验证码、Authorization等默认遮盖或不进入日志；复制成功必须来自真实复制结果，失败给手动复制文本。

## 6. 欢迎、帮助与教学

欢迎先说“让 AI 帮你，从这里开始”，一次只说明当前步骤。引导可以返回、跳过或结束；提示必须指向可见目标。外部安装写“安装后回来重新检测”，不把按钮点击写成已装好。帮助从具体问题进入相应教程、检查或配置，返回保留原任务。

避免“全部自动搞定”“绝不丢数据”“永久可用”等无法由当前状态证明的承诺。模拟边界写在检阅工具与交付说明，不在每张产品卡片反复插入技术免责声明。
