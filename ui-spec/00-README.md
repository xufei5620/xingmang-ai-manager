## 使用顺序与事实分层

1. 先读本页、[交接说明](HANDOFF.md)、[源码历史核对](12-github-code-review.md)与[UI 契约矩阵](15-ui-contract-matrix.md)，再按页面查看组件、状态和验收。
2. 优先级：用户当前及持续有效指令 → 本轮已授权设计规范 → 组件/状态规则 → 可交互原型 → 历史截图。冲突要回查依据并修正规范或原型，不能把明显演示错误复制到产品。
3. **代码已有**：固定 GitHub 提交 `0c9ec4a5a3c9cf31fa0e05c33725cd31ae73e39e`、版本 `0.1.31` 的静态证据见 12；不代表今天远端状态或真机运行结果。
4. **本轮新增设计**：原型可操作的 UI 流程和新的呈现规则，包括多账号隔离、平台替代入口与异常恢复；模块源码是交互定位依据。
5. **仍需真实集成**：接口、IPC、文件读写、凭据保存、订单查询、原生窗口、系统能力及发布。逐项证据在实现时补齐，UI 模拟通过不能替代这些证据。
