## 1. 窗口尺寸与缩放

首次无有效记录时，宽度取工作区宽 × 0.80 并限制在 960–1440，高度取工作区高 × 0.85 并限制在 560–900。工作区低于 1280×720 时优先最大化；小于最小目标 960×560 时按真实可用工作区处理，避免不可达窗口。1280×820 是设计/截图样例，不是固定默认窗口。

保存并恢复 bounds 与 maximized；保存位置已不在任何屏幕时回主屏可见区域。真实 Electron 与存储接入点按仓库约定实现，不能照本规范新建固定目录。

自动倍率 = clamp(内容区宽度 / 1280, 0.9, 1.25)；用户“自动 / 90% / 100% / 110%”对应乘数 1 / 0.9 / 1 / 1.1；最终倍率 = clamp(自动倍率 × 用户乘数, 0.85, 1.25)。内容区按 DIP 计算，系统 DPI 不再次手工乘入。“100%”是自动倍率的 1 倍，不保证最终 zoom 为 1。

2026-10-14（v4.0，产品负责人确认）：下限从 0.7 提到自动 0.9、最终 0.85，960 × 560 最小窗口时界面缩放是 90%，字不再小到看不清；窗口窄时靠侧栏收窄条腾地方。

最终 85/100/125% 属于测试注入，记录时注明跳过用户乘数。文字不能为防重叠无限缩小；最低倍率同时检查阅读与点击，不能只验几何无溢出。

## 2. 外壳与滚动

| 区域 | 规则 |
|---|---|
| 标题栏 | 登录后并进顶栏：Windows/Linux 系统三键那条高 44（界面缩放 90% / 110% 时 40 / 48，跟着顶栏），顶栏右边给它们让出位置；macOS 红黄绿压在侧栏顶上，侧栏上边留 42、收成窄条时顶栏左边让 32。登录前那条单独的标题栏 Windows/Linux 44、macOS 46 |
| 侧栏 | 展开 224px / 折叠 60px，品牌图形和字标按 07；整条可拖动窗口 |
| 顶栏 | 44px，整条可拖动窗口；左边当前位置（页名，个人中心后面跟页签名），中间搜索框 300×30（「搜索或跳转」，右边按系统写 Ctrl K 或 ⌘ K），右边深浅色、公告、帮助三个 30 见方的图标键、间距 2。公告点开是铃铛下面 320 宽的小框：每条是标签、标题、日期和正文第一句，没读的左边一个金点，有没读的时右上「全部已读」；点外面或按 Esc 收起，再点铃铛也收起；点一条才开大框看全文，旧式只有一段文字的公告读完直接开大框。小框每次打开都重新读一遍 |
| 内容区 | 每页正文最宽 1000，在侧栏右侧居中：窗口再宽只是两边留白变多，窄了留白从 32 收到 16；上边距 28；页面独立纵向滚动；页头标题、说明与该页动作 |
| 状态栏 | 28px；左边环境状态、Node.js 版本、登录、USD 余额、网络，右边「已装 N 个工具」和版本号。环境状态：绿点「环境正常」、橙点「N 项需要处理」（只数检查页的「待处理」，和开机那条提示一个口径）、灰点「环境待检测」（还没检查过）；悬停写各运行环境版本，没装的写「没装」。Node.js 没装写「Node.js 没装」，没检测成写「Node.js 检测失败」。版本号有新版本时金色写「· 有新版本」，下好了写「· 重启后更新」，点开更新页 |

首页保留左侧工具与右侧摘要（292px）双栏。其余页面按既有单栏或页内二级导航组织；不重新设计成移动端卡片流。列内可柔性分配；表格宽内容由自身容器横向滚动，操作列与状态不能裁掉。

工具行基准为图标 40、名称 minmax(120,200)、状态 minmax(86,1fr)、来源/附加信息 72、主动作 92、更多 32px；具体复合行按共享变体调整。长名称省略并提供全文，状态最少 86px且可换行；窄宽优先压缩名称与说明，不隐藏关键动作。

Dialog 标准 480 / wide 640，Drawer 420；正文独立滚动，关闭和 footer 可达。产品 Drawer 避让顶栏 44 和状态栏 28；Drawer 不是模态框：背后不罩、不模糊，列表照样能点，点另一行就换成那一行，Esc 关；footer 按钮从左往右排、主按钮在最左，放不下换行。Notice 在状态栏上方16。开机提示卡贴右上角、顶边在 64（压着顶栏下沿），背后不放半透明方块；不挪到正文顶上，那里是各页页头的主按钮。公告条和断网条共用顶栏下面那一个位置：断网时只显示断网条（顶栏「公告」的小红点照旧），联网后公告条回来；断网条上的按钮叫「重试」，点了还是不通就提示「还是连不上网。网络恢复后这条提示会自己消失」。浮层焦点与草稿见 [02](02-components.md)。

状态栏的网络位置写「网络正常 · 国家」，国家和 IP 的全文在悬停说明里，可点击刷新；游戏加速连着时写「加速中 · 线路名」。游戏加速连接成功、线路变化和确认停止后自动检测；过程中显示「正在检测网络位置…」，没测出国家只写「网络正常」，悬停写「网络位置未知」。断网时这一项不出现。停止未确认时保留原位置，不使用线路名称填造出口。按钮沿用状态栏 24px 密集控件规范，保留 `shell-network-location` 测试标记。

## 3. 分组导航

| 分组 | 入口 |
|---|---|
| 工作（不写标题） | 首页、聊天、记录、画布（独立窗口标记） |
| 扩展 | 外接工具、技能、插件（小标题「扩展」） |
| 服务（分隔线隔开） | 充值（个人中心的充值页签，余额低时后面一个「余额低」小标签）、教程、检查（有待处理时带数字角标）、反馈与客服；底部钉住：更多（游戏加速 / 安装卸载 / 备份 / 更新，v4 里各有新去处，去处落地一个删一个）、设置 |
| 账号区域 | 头像、名字、套餐（按量付费的写「按量付费」）、余额、进度条、「约还能用 N 天」；整张卡点开个人中心 |

分组之间用分隔线，只有「扩展」带小标题。导航图标 16、标签 13.5、行 34、圆角 8、gap 10；当前页用 `--nav-on` 底和 `--nav-on-sh` 细边（深色是一道淡金渐变，浅色是白底），图标金色。「更多」展开的子页行 30、往里缩进。首页后面的数字是可更新的工具数，检查后面的数字是待处理项数，两个角标都写进可访问名称，只补充文字状态。

「更多」和「设置」不跟着滚：两项钉在导航底部（上方一条分隔线），展开时四个子页排在「更多」和「设置」之间。展开还是收起记在本机，下次打开照旧；打开四个子页中任何一页时自动展开。上面那段导航放不下时自己滚，上下边缘按滚动位置渐隐（20px），换页时把当前那一项滚进可视区（离边缘 16px）。窗口逻辑高度不到 660（按缩放折算后）时导航行 34→30、「更多」子页 30→28、分组间距减半——这是两个断点里管高度的那个，只服务侧栏放得下。

窗口逻辑宽不到 1280（按缩放折算后）时侧栏自动收成窄条，正文照旧 1000 宽；这时点「展开侧栏」不展开、提示「窗口较窄时侧栏会自动收起」（v4 去掉了浮在页面上的那层展开）。窗口变宽后回到用户自己上次设的展开或收起，自动收起不改这份记录。

折叠后保留全部入口的可访问名称与 Tooltip；顶上只留品牌标志，悬停或聚焦时换成「展开侧栏」按钮。账号区域仍能打开个人中心，不能压成无法操作的小点；折叠时只留头像。账号卡（v4）：描金边，头像、名字（历史账号后加小标签「历史账号」）、下面一行套餐；「余额」和金额；一道进度条（按最近 7 天用量算还能用几天，30 天算满）和一行「按最近用量，约还能用 N 天」，不够 7 天时写「余额不多了，…」、卡片和侧栏「充值」一起标余额低；算不出用量时不画进度条，按不到 $5 算余额低。卡片右上一颗「收起侧栏 / 展开侧栏」。充值和切换账号不放在卡上：充值在侧栏「充值」那一行，切换账号在个人中心页头。余额平时不放刷新键（首页余额卡、状态栏悬停和个人中心能刷新），读失败了卡上才出「更新失败」和刷新键。恢复登录中头像位置是空白头像加转圈、金额位置是灰色占位条；余额没读到写「—」，悬停说明「余额暂时没有读到，点刷新再试」。侧栏导航独立滚动，账号区不会被长导航推出可视区。设置另有八项二级导航，一次只渲染一组面板，见 [04](04-pages.md)。

顶栏命令入口与 Ctrl/⌘ K 相同，灰字「搜索或跳转」；正常导航始终保留。命令面板（v4）是不带标题行的 560 宽、圆角 14 的 Dialog（标题只给读屏），框顶固定在窗口高度约 1/6 处，输入框 46 高、不带边框，右边一颗「Esc」键帽，灰字「输入页面、工具或操作，比如「充值」」；结果区最高 320、多了在框里滚，每行 36，输入时框不跳；什么都没输时先列「操作」（充值、查看用量账单、开始检查、帮助与客服，以及切到另一套深浅色、登录时的退出登录），再列「页面」；底部一行键帽「↑↓ 选择　Enter 打开　Esc 关闭」（输入框里有字时第一下 Esc 先清空文字，这是搜索框自带的，照旧）。输入后结果按页面、操作、个人中心、设置、教程分组；搜不到写「没有找到「词」相关的内容」；设置里每一行单独一条，写成「组名 › 行名」，选中后打开那一组、滚到那一行并亮一下（减少动画时只加一圈边框），这台电脑没有的行不出现。个人中心组除了九个页签另有一条「切换账号」，落在个人中心页头那颗按钮上，停在当前页签。页级动作放页头或任务容器，不挤入顶栏。

## 4. 独立窗口与关闭

画布是独立窗口设计，默认目标1200×760并记住尺寸；本原型在页面内模拟。关闭画布仅结束该窗口，未保存修改及运行中任务按画布规则保护。付款展示目标480×720且受工作区约束；支付方式按真实 URL/POST 表单能力选择，关闭后订单仍可查询。启动闪屏显示当前阶段，主窗口就绪后结束。

关闭偏好保留询问、缩到托盘、直接退出。**无托盘时保留窗口和任务栏入口，只有明确选择直接退出才退出**；不能隐藏到无法找回的位置。macOS 将菜单栏与 Dock 表述清楚，具体原生行为由能力适配器确定。托盘菜单保留打开星芒、已装工具、充值、更新、设置、退出入口。

安装、保存、画布运行等未完成时，关闭先说明当前影响并提供继续等待/返回或实际可取消动作。只有真实完成后才提示已退出、已隐藏或已取消。二次启动与深链需要 show/focus 的设计通过原生接入验证，不由浏览器弹层代替。

## 5. 键盘与返回

| 输入 | 设计动作 |
|---|---|
| Ctrl/⌘ K | 打开命令面板 |
| Ctrl/⌘ , | 打开设置 |
| Ctrl/⌘ 1–5 | 按首页顺序打开工具；不可用时解释准备条件 |
| F11（Win/Linux）/ Control+⌘ F（Mac） | 当前窗口全屏，真实支持按平台验证 |
| Esc | 最上层浮层/引导关闭，遵守草稿保护 |
| Enter / Shift+Enter（聊天） | 发送 / 换行，中文组合输入中不发送 |
| /（有搜索的列表） | 非编辑上下文聚焦搜索 |

窗口关闭、退出快捷键遵循系统约定并处理进行中任务；不全局抢占输入框的 Ctrl/⌘ W/Q 等编辑行为。列表→详情→编辑→返回保留筛选、页码、选中项和滚动；帮助/检查跳往修复入口后保留“返回检查”路径。系统快捷键与原生菜单单独验收。
