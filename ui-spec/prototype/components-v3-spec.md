# 星芒 AI · 组件检阅 v3 规范

对应页面：[components.html](components.html)。本页是设计检阅工具，保留主应用布局；示例只改变当前页面，不连接 HTTP 服务、不安装工具、不读取真实文件或凭据。

## 目录与版本边界

本版登记 **45 种组件**，使用独立编号 `V3-001` 至 `V3-045`。编号按本次组件清单固定，页面按用途分组显示，不以页面展示顺序重排编号。

原版 21 项编号继续有效；下方保留映射。原 `Brand` 是品牌与图标底座，不额外计入本次 45 种业务组件。原 `Input`、`Menu`、`Progress`、`Callout` 中的多种职责拆为独立登记项。

## 共同规则

- 引用 `../tokens.css` 的品牌色、主题、语义色、字体族、圆角与层级。V3 共享基线为普通正文 **14px / 1.5**，主控件 **36px** 高，紧凑控件 **32px** 高，小号控件 **28px** 高。主应用与本检阅页使用同一基线；顶栏和状态栏的密集例外见 01。真实产品代码未修改。
- 导航图标 **20px**，按钮图标 **18px**；可点击的图标按钮 **36 × 36px**。图标使用 `work/modules/60-icons.svg` 中 Lucide 0.468.0 的 51 个符号，原几何与许可证一并内联。品牌 favicon 继续引用原品牌资产，不用通用图标替代品牌标识。
- 标签与说明使用普通中文；`Codex`、`Claude Code`、`API Key` 等保留真实技术名称。代码、服务地址与 Key 使用等宽字体；不把整页正文改成等宽字体。
- 正常、警告、错误同时使用明确文字；焦点有可见外环。禁用态仍保持标签可读，不只依赖低透明度说明不可用。
- 检阅控制包含深浅主题、高对比、减少动画、Windows/macOS/Linux 字体与快捷键展示、典型状态筛选。平台控制是浏览器内呈现模拟，不代表原生系统兼容验证。
- “全部典型状态”展示每种组件有意义的状态。“可交互”“静态样例”“错误与恢复”是组件筛选，不是给全部组件强行切换五套状态。
- “可交互”只承诺当前示例实际具备的本地操作；“静态样例”不伪装成完整业务流程。表格、统计、记录均为虚构数据。文件选择仅加入预置示例文件名，Key 显隐仅展示虚构字符串。
- 960px 宽度下保留目录与独立内容滚动。内容过宽时由表格容器滚动；控制条允许换行。小于 760px 时隐藏侧目录，组件改为单列。减少动画同时尊重系统媒体查询。

### 页签激活方式

页签分为两种明确变体：组件检阅页使用手动激活，方向键移动焦点，Enter/Space切换内容；设置页的八组本地内容使用自动激活，上下键立即切换对应面板。两种方式都必须同步选中态、aria关联和可见焦点，不能在同一个页签组里混用。
