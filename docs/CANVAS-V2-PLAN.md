# 无限画布 v2：节点式 AI 媒体工作流

> 当前实现与安全架构记录，更新于 2026-08-13。历史上的 M0 三节点方案已经被本版本取代；与本文冲突时以代码和测试为准。

## 1. 产品定位

无限画布是星芒 AI 管理工具箱内的本地媒体生产工作台。用户通过节点、类型化端口和连线组织提示词、图片、视频与结果，而不是在浏览器中保存供应商凭据或直接请求生产接口。

首版聚焦单用户、本地优先的创作闭环：编辑工作流、按范围运行、查看候选和费用、采纳产物、管理本地资产、导入导出项目。多人协作、远程插件市场、CRDT、3D 导演工具和完整多轨时间线不在本版范围内。

## 2. 当前架构

```text
Canvas renderer（sandbox + contextIsolation）
  React Flow / 编辑命令 / schema v2 / assetId
                 |
                 | 窄类型 IPC；无 API Key、会话或供应商请求
                 v
Electron main
  sender 校验 / 分组与 Key 协调 / DAG 调度 / 运行历史
  AI 服务 / 项目包校验 / 当前账号专属资产库
                 |
                 v
xm.solov.cc + <安装根目录>/output
```

- Renderer 的 CSP 使用 `connect-src 'none'`，不能自行访问生产服务。
- 分组选择和模型参数可以进入 renderer；API Key、access token、refresh token 不进入 renderer 状态、工作流或构建产物。
- 运行事件携带 `runId`、`graphRevision` 和递增 `sequence`；主进程负责并发、取消、缓存与终态。
- 账号切换会取消旧账号的运行和生图操作。资产与运行历史均按当前登录用户归属读取。

## 3. 节点与编辑器

第一版提供 10 个正交媒体节点：提示词、图片素材、视频素材、图像生成、图像编辑、视频生成、视频抽帧、路由、候选画廊、输出；另有分组、便签和未知节点占位。旧版 `text`、`image`、`video` 仅用于兼容迁移。

编辑能力包括：

- Undo/Redo、复制、粘贴、重复、删除和快捷键。
- 多选分组、解组、锁定信息持久化和确定性自动布局。
- 统一创作内容库：可搜索节点、星芒原创提示词预设、账号隔离的用户提示词预设、工作流模板和当前账号素材入口。
- 素材可从内容库点击或拖放到画布，完整搜索、分页和文件操作由独立素材栏承载；三套内置模板保持星芒原创。
- 未识别节点以禁用占位符恢复，避免导入旧项目时静默丢失数据。

节点定义由 `CanvasNodeDefinition` 注册表统一提供版本、默认数据、端口、尺寸、校验和执行器键。供应商差异放入模型能力与参数，不通过复制大量供应商专属节点扩张目录。

## 4. 运行语义

主进程运行服务支持四种范围：全部、仅变更、选中链路、运行到节点。执行器按 DAG 就绪顺序推进，并提供：

- 有界并发和分支失败传播。
- 用户取消、迟到结果抑制和终态只提交一次。
- 输入指纹缓存，避免重复付费执行未变化的上游节点。
- attempt、候选、耗时、费用和错误记录。
- 运行历史恢复、候选预览及显式采纳。

图像生成和图片编辑已连接现有主进程 AI 服务；图片编辑支持 1-4 张当前账号的本地参考图。其他供应商能力在缺少已验证执行器时会明确失败，不伪造成功结果；自动化测试一律 mock，不请求生产 `xm.solov.cc`。

### 后续生态优先级

基于多项目的公开行为研究，后续按以下顺序独立实现，不复制受限项目表达：

1. 提示词预设、工作流模板和账号资产形成统一的可复用内容库。
2. 删除运行历史或产物前计算画布、候选和项目包引用，默认保留仍被引用的资产。
3. 用主进程有界批处理替代普通前端循环：必须设置次数、并发、费用预算和手动停止上限。
4. 外部 ComfyUI、浏览器采集、Photoshop 连接器和完整时间线暂不进入当前桌面版，待单独完成信任边界设计。

## 5. 持久化与项目包

工作流 schema 当前为 v2，读取时支持 v1 迁移。序列化会剥离凭据字段、远程 URL、base64、绝对路径和不安全设置，只保存稳定 `assetId` 与有界元数据。

桌面版 `.xingcanvas` 项目包可以携带工作流和被引用的本地图片：

- 导入前展示节点、连线、资产数量和警告。
- 总包上限 96 MB、最多 64 个资产、单资产上限 64 MB。
- 校验 MIME、文件签名、SHA-256、字段白名单和敏感字段。
- 导入采用暂存、资产 ID 重映射和失败回滚。
- 当前只内嵌 PNG、JPEG、WebP；视频仅保留工作流引用，不嵌入包内。

浏览器独立开发模式保留轻量 JSON 兼容导入导出，但不连接生产服务。

## 6. 资产模型

生成图片由 `AiAssetStore` 保存到安装根目录的 `output/`，索引按账号所有权隔离。UI 支持刷新、拖入画布、复制、另存和定位文件。工作流不依赖短期供应商 URL，也不写本地绝对路径。

每次生成形成不可变 attempt，候选结果在用户点击采纳前保持同级。缓存与历史只引用经过归属校验的本地资产。

用户提示词预设存入当前账号专属的 `canvas-content/user-<id>/prompt-presets.json`：主进程限制 500 条和 2 MB，使用串行更新、原子 UTF-8 写入和损坏文件隔离。Renderer 不传账号标识，只通过字段明确的 CRUD IPC 读写纯文本内容。

## 7. UI 约束

- 默认使用中性近黑画布与低对比点阵，节点、工具栏、面板、React Flow Controls 和 MiniMap 共用一套令牌。
- 节点类型使用细窄强调色、图标和端口标签区分，不整块染色；运行状态同时使用文字和边框，不只依赖颜色。
- 固定节点宽度和媒体宽高比，避免加载或状态变化引发布局跳动。
- 验收视口为 960x620、1366x768、1590x875 和 4K；需要覆盖节点库、资产栏和运行栏组合打开的状态。

## 8. 许可证与来源边界

运行时底座使用 React、React DOM、React Flow 和 Lucide React，精确版本与许可记录在 `docs/canvas-third-party.json`。当前没有改编第三方文件、外部素材或外部模板。

GPL/AGPL、限制许可和无可靠许可证项目仅用于形成公开行为需求与独立验收测试。即使同时研究多个项目，也不能通过“融合”规避版权：不得复制其源码、文案、截图、素材、模板或独特视觉表达。采用任何宽松许可代码前仍需做 commit 和逐文件许可审计，并记录目标文件、版权与修改摘要。
