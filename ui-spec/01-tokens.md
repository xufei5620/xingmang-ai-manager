# 01 · 设计 Token 与尺寸作用域

2026-10-14：界面基线换成 v4.0，见 [v4/README](v4/README.md)。v4 只留两套配色（黑金深色、晨曦金浅色），雾青、极光紫去掉；令牌值以 v4 原型的「组件规范」为准。

2026-10-15（v4 批01 底座）：`tokens.css` 已换成 v4 的两套配色和尺寸，本文件跟着改；没提到的地方仍是 v3.1.1 的规则。

v3.0 起颜色与共享变量的实际定义是 [tokens.css](tokens.css)。主原型、组件检阅页统一采用正文14px、主控件36px、紧凑32px、小控件28px；局部密集例外在本节明确登记。

## 1. 品牌与语义色

| 品牌变量 | 值 | 角色 |
|---|---|---|
| `--xm-navy` | #0B1F3B | 曜石海军蓝 |
| `--xm-gold` | #D4A355 | 日出金 |
| `--xm-ivory` | #FAF7EE | 暖象牙白 |
| `--xm-sky` | #A7D1F7 | 晨光蓝 |
| `--xm-slate` | #3D5B8F | 晨曦石蓝 |
| `--xm-mist` | #E6EEF6 | 薄雾浅灰 |

组件引用语义变量：`--win/--rail/--bg` 是外壳、导航与内容；`--panel/--panel-solid/--panel-2` 是卡片、浮层和控件；`--text/--text-2/--text-3` 是正文、说明、辅助；`--line/--line-2/--line-3` 是分隔与边框；`--info` 是信息；`--ok/--warn/--bad` 及淡底是成功、注意、错误的图形色。

v4 新增的语义变量（名字照原型）：

| 变量 | 用在哪 |
|---|---|
| `--pri` / `--pri-tx` / `--pri-sh` | 主按钮的底（深色金色渐变、浅色海军蓝渐变）、字和光影 |
| `--accent` | 主按钮那一色的单色别名，给不能用渐变的地方（`--accent-fg` 是它上面的字） |
| `--gold` / `--gold-tx` | 选中、指示条、目标描边用 `--gold`；金色文字用 `--gold-tx` |
| `--num` | 余额、金额这类大数字 |
| `--fill` | 进度条 |
| `--soft` / `--soft-line` / `--soft-tx` | 金色淡底的标签、气泡边 |
| `--ok-tx` / `--warn-tx` / `--bad-tx` / `--info-tx` | 状态**文字**一律用 `-tx`，`--ok/--warn/--bad` 只给图标、圆点和描边 |
| `--focus` | 键盘焦点环 |
| `--input` / `--input-line` | 输入框的底和边 |
| `--pop` / `--pop-line` / `--shadow-pop` | 弹窗、菜单、导览气泡、提示气泡 |
| `--toast` / `--toast-tx` / `--toast-ok` / `--toast-info` / `--toast-warn` | 右下角的短提示和它的图标 |
| `--sw-on` / `--seg-on` | 开关打开、分段选中的底 |
| `--sh-1` | 卡片阴影 |

深色主按钮是金色渐变配深色字；浅色主按钮是海军蓝渐变配白字。警告用橙色。状态同时有文字；余额、Key、官方额度分别由自己的状态来源决定。正文、状态文字和必要说明检查 4.5:1 对比，焦点环、输入框边、开关打开检查 3:1（`src/renderer-v2/styles/contrast-tokens.test.ts`）。高对比是补充模式（`src/renderer-v2/styles/tokens.css` 里每套主题各一整套值），不能掩盖默认主题不可读。

## 1A. 皮肤（v4 已去掉）

v3.1 的四套皮肤（晨曦金、极夜黑金、雾青、极光紫）在 v4 里去掉，主窗口只按 `data-theme` 上色，不再设 `data-skin`。

- 设置里存的 `uiSkin` 字段**不删**：删了会让软件把下次启动当成第一次启动，把主题切回浅色。存着的值照旧导入导出，只是主窗口不再用它。
- 画布窗口还按存着的 `uiSkin` 上色（画布和主窗口共用 `src/renderer-v2/styles/tokens.css`），所以那里的皮肤规则暂时留着，等画布那一批定了「画布跟深浅色」再删。
- `work/modules/99-skin.css` 是 v3.1 原型的皮肤定义，只作历史参考。

## 2. 字体与尺寸

macOS 使用系统与 PingFang，Windows 优先 Segoe UI / Microsoft YaHei UI，Linux 优先 Noto Sans CJK SC 并回退。字体随包分发时核对许可、缺字与体积。等宽字体用于路径、命令、Key、版本、时间戳、任务 ID 和比较数值，中文正文不使用等宽字体。

| 项目 | 基础 Token / 主应用现值 | v3 组件页规则 |
|---|---|---|
| 欢迎 Display | 42px / 1.12 / 700 | 不另设全局覆盖 |
| 页标题 / 区块标题 | 22px / 15px | 沿用 |
| 正文 | `--font-body:14px` / 1.5 | 同一共享基线 |
| 列表主名称 | 14px | 14px |
| 辅助 / 微型 | 12–12.5px / 11.5px（v4 起最小 11.5） | 不用微型字承载必读说明 |
| 普通控件 | md 36、sm 32、xs 28px | 主控件36、紧凑32px |
| 弹窗标题 | `--font-dialog-title:17px` | v4 起没有图标 |
| 导航 | 50 模块：字 14、行 36、gap 10px | Sidebar 样例行至少 40px |

主应用与组件页采用统一尺寸基线并保留区域结构。密集数据可用13px、辅助说明12–12.5px；顶栏按钮32px、状态栏按钮24px是明确例外，不把所有控件强行撑成36px。导航行36px保持既有结构。

## 3. 空间与命中范围

间距以 4px 为基础，允许既有 10/14/18px 关系。页面 padding 28×32，卡片常用 16/18，行间 8/10/12。输入圆角 8、按钮 9、卡片 13、Dialog 16；窗口外角由 [08](08-platform-matrix.md) 的平台呈现场景覆盖。

导航功能图标 20px；按钮图标 18px，普通行内图标 16px；v3 图标按钮 36×36。品牌底座与功能图标分开，见 [07](07-icons-brand.md)。

固定结构：侧栏 216/60、标题栏 36、顶栏 46、状态栏 30、Dialog 460/640（v4 起标准宽 460）、Drawer 420、导览气泡 264、短提示最宽 380；工具状态列至少 86px（外壳尺寸改成 v4 的那批再更新侧栏、顶栏、状态栏）。单位均为逻辑像素，不手动乘系统 DPI。

## 4. 动效与层级

颜色/hover 150ms，浮层进入 220ms，进度宽度 300ms，加载旋转约 800ms；v4 起缓动统一用 `cubic-bezier(.22,1,.36,1)`。欢迎页的轨道与光点在品牌周围运动，品牌本身不变形、重绘或加材质。装饰动效不承载任务结果。

系统减少动画或应用设置开启时关闭轨道、呼吸、旋转和位移，保留静态进度、阶段文字、错误和焦点。余额低于 $5 时充值按钮允许 1.8s 呼吸提示（产品决策：用户需要随时感知该充值）；减少动画开启时改为静态红色。

基础层级：Drawer 15、Notice 18、Dialog 20、Popover 25、Toast 30、Coachmark 35、画布模拟窗口 40。仅最上层模态可操作；子菜单和 Tooltip 隶属所属浮层，页面不能自行加层级逃逸焦点管理。调试控制在产品窗口外。

Token 修改同步组件页与引用方；按 [10](10-acceptance-checklist.md) 验证可读性与键盘行为，变量存在不是验收证据。
