## 用户

- 在设置里「导入」另一台电脑的聊天记录时，这台电脑上原有的对话一个都不会再被删掉：
  以前加起来超过 50 个对话时，会悄悄删掉这台电脑上最老的几个。现在存不下的那几个先不导，
  提示会说还差几个；在「聊天」里删掉一些不要的对话，再点一次「导入」就能补上，已经导进来的不会重复。
