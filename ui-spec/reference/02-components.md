# 02 · 组件规范 v3.0

本版登记 45 种组件，编号固定为 V3-001 至 V3-045；保留旧 21 项映射。登记来源是 [components-v3-spec.md](prototype/components-v3-spec.md)，操作入口是 [components.html](prototype/components.html) 与 [v3 源页](prototype/components-v3.html)。下表中的“本页”均指组件检阅页，不等于主应用每个同名控件已完成相同行为。

尺寸规则见 [01](01-tokens.md)：主应用和组件页统一正文14px、主控件36px、紧凑32px、小控件28px；顶栏32px和状态栏24px按钮为密集场景例外。45 项中静态 Menu、Popover、Notice、Coachmark、Sidebar、OTP 必须继续完成产品交互与键盘接入，不能以静态样式列为功能通过。

页面使用 Stack、Inline、Grid、Split、ScrollRegion 等共享布局原语组合组件。页面可以决定内容顺序与列宽，不能私自定义新的颜色、危险动作规则、焦点管理或错误体系。

## 完整产品共同契约

### 动作与状态

同一任务容器最多一个 primary；独立任务卡、列表行和最上层弹窗可各有主动作。同一任务重复入口不同时强化。危险操作使用 danger，描述真实对象与影响。loading 保留动作名称、宽度和可访问状态；阻止重复提交，仅锁定相关字段。

### 表单、子流程与返回

每份表单按流程实例保存：来源入口、对象 ID、所选页签、字段草稿、初始值、dirty、提交阶段、错误、返回焦点及滚动位置。失败保留输入；字段错误关联 aria-invalid / aria-describedby，提交后聚焦首个可修正字段。中文组合输入期间 Enter 不发送聊天或提交表单。

优先在同一 Dialog 切步骤；必要时允许受控子 Dialog。工具配置 → 新建 Key、选择文件夹、选择保存方式均保留父工具、来源、模型、Key、字段与滚动。子流程成功只更新对应字段，返回不重建父流程。配置页签切换必须保存该页签草稿；不能把上个工具的字段带到下个工具。

未修改的表单可由关闭/取消/Esc 结束；有修改时遮罩不关闭，关闭/取消/Esc 显示“继续编辑 / 放弃修改”。只有明确放弃或提交成功才清除本次草稿。只读详情不显示无意义保存确认。

### 浮层与键盘

Dialog 标题关联、modal 与可见焦点必须齐全。打开聚焦首个有意义控件或标题；Tab/Shift+Tab 仅在最上层模态循环；Esc 只作用最上层且遵守草稿规则。关闭后回触发器，触发器消失时回逻辑后继。最上层子窗打开时父窗和背景不可操作。

标准 Dialog 宽 480、wide 640，两侧至少留 16px，正文滚动而头/尾操作可达。产品 Drawer 宽 420，避让顶栏 46 与底部状态栏 30；非模态详情需明确背景焦点路径，阻塞表单则按 Dialog 管理。Notice 位于状态栏上方 16px。

Tabs 采用手动激活：方向/Home/End 移焦点，Enter/Space 激活，Tab 进入面板。Segment 用于少量互斥筛选；业务设置可使用原生 radio 或已登记 group/pressed 变体，不混用 tab 语义。Menu 用方向键、Home/End、Enter/Space、Esc，含表单的 Popover 使用普通表单语义。

### 列表与导航

ToolRow 名称可收缩，状态列至少 86px，动作不因长文本被裁掉；同表共享列轨道。Table 有语义表头，必要时容器独立横向滚动，数值右对齐；分页保留筛选，不编造未知总数。主应用侧栏固定 216/60，导航分组与设置单面板见 [03](03-layout-window.md)、[04](04-pages.md)。

### 反馈与能力

FieldError 管字段，Banner 管区域，Error 管任务恢复，Toast 只报告已确认短结果。成功、警告、错误均带文字，禁用项说明原因与替代入口。只读、未安装、功能不支持、凭据失效是不同状态，不能统一置灰整行。统计图必须有单位、时间范围、指标口径和文本替代。

所有浏览器示例中的数据、文件选择、Key、验证码、进度与订单均按样例边界解释。产品适配时使用真实结果，不能用定时器和按钮点击替代任务完成。验收条目见 [10](10-acceptance-checklist.md)，通过数量仅引用[16最终验证记录](16-final-validation.md)。



### 页签激活方式

页签分为两种明确变体：组件检阅页使用手动激活，方向键移动焦点，Enter/Space切换内容；设置页的八组本地内容使用自动激活，上下键立即切换对应面板。两种方式都必须同步选中态、aria关联和可见焦点，不能在同一个页签组里混用。
