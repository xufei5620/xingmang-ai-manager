# 01 · 设计 Token 与尺寸作用域

v3.0。颜色与共享变量的实际定义是 [tokens.css](tokens.css)。主原型、组件检阅页统一采用正文14px、主控件36px、紧凑32px、小控件28px；主原型组合 `work/prototype.css` 与各模块覆盖。局部密集例外在本节明确登记。

## 1. 品牌与语义色

| 品牌变量 | 值 | 角色 |
|---|---|---|
| `--xm-navy` | #0B1F3B | 曜石海军蓝 |
| `--xm-gold` | #D4A355 | 日出金 |
| `--xm-ivory` | #FAF7EE | 暖象牙白 |
| `--xm-sky` | #A7D1F7 | 晨光蓝 |
| `--xm-slate` | #3D5B8F | 晨曦石蓝 |
| `--xm-mist` | #E6EEF6 | 薄雾浅灰 |

组件引用语义变量：`--win/--rail/--bg` 是外壳、导航与内容；`--panel/--panel-solid/--panel-2` 是卡片、浮层和控件；`--text/--text-2/--text-3` 是正文、说明、辅助；`--line/--line-2/--line-3` 是分隔与边框；`--accent/--accent-fg/--accent-soft` 是主动作；`--info` 是信息；`--ok/--warn/--bad` 及淡底是成功、注意、错误。

深色主动作是金色配海军蓝文字；浅色主动作是海军蓝配白色文字。警告用橙色。状态同时有文字；余额、Key、官方额度分别由自己的状态来源决定。正文和必要说明检查 4.5:1 对比；高对比是补充模式，不能掩盖默认主题不可读。

## 1A. 皮肤（整氛围主题）

v3.1 新增。皮肤是用户级个性化：在暗色/亮色之上整体替换中性色与强调色家族。四套皮肤：

| 皮肤 | data-skin | 暗色基调 | 亮色基调 | 气质 |
|---|---|---|---|---|
| 晨曦金（默认） | `dawn` | 深海军蓝 + 日出金 | 暖象牙白 + 海军蓝 | 即本文件第 1 节的基准值，不覆盖任何变量 |
| 极夜黑金 | `obsidian` | 近纯黑 #0B0C10 + 香槟金 #E0BE7C | 暖纸白 #F7F3E9 + 黄铜 #96702C | 沉稳高级感 |
| 雾青 | `mist` | 深石板青 #0C1A1E + 青碧 #43C6B8 | 冷白 #F0F6F5 + 深青 #0F7A72 | 清爽安静 |
| 极光紫 | `aurora` | 紫夜 #120F22 + 紫罗兰 #9B8CF7 | 薰衣草白 #F3F1FB + 靛紫 #6A5AE0 | 夜间科幻感 |

规则：

- 皮肤只允许重映射这些变量族：`--win/--rail/--bg`、`--panel/--panel-solid/--panel-hover/--panel-2`、`--line/--line-2/--line-3`、`--text/--text-2/--text-3`、`--accent/--accent-2/--accent-fg/--accent-glow/--accent-soft`、`--info`、`--overlay`、`--btn-2-bg/--btn-2-hover`、`--glow-top`、`--tile-ring`、`--card-grad`。亮色模式下各皮肤的主动作加深配白字，对比度不低于 4.5:1。
- `--ok/--warn/--bad` 语义色**不随皮肤变化**，避免状态误读；品牌六色（`--xm-*`）不随皮肤变化。
- 高对比模式（`.hc`）的线色与次要文字规则压过皮肤基调，可读性优先。
- 每套皮肤的完整变量值定义在 `work/modules/99-skin.css`，与 00 基准同字段对齐；新增皮肤必须同时给出暗/亮两套定义并通过 10/50 组检查。
- 皮肤选择器在设置-外观（皮肤芯片组件，见 02）；检阅条的皮肤下拉只用于验收预览，不进产品。

## 2. 字体与尺寸

macOS 使用系统与 PingFang，Windows 优先 Segoe UI / Microsoft YaHei UI，Linux 优先 Noto Sans CJK SC 并回退。字体随包分发时核对许可、缺字与体积。等宽字体用于路径、命令、Key、版本、时间戳、任务 ID 和比较数值，中文正文不使用等宽字体。

| 项目 | 基础 Token / 主应用现值 | v3 组件页规则 |
|---|---|---|
| 欢迎 Display | 42px / 1.12 / 700 | 不另设全局覆盖 |
| 页标题 / 区块标题 | 22px / 15px | 沿用 |
| 正文 | `--font-body:14px` / 1.5 | 同一共享基线 |
| 列表主名称 | 14px | 14px |
| 辅助 / 微型 | 12–12.5px / 11–11.5px | 不用微型字承载必读说明 |
| 普通控件 | md 36、sm 32、xs 28px | 主控件36、紧凑32px |
| 导航 | 50 模块：字 14、行 36、gap 10px | Sidebar 样例行至少 40px |

主应用与组件页采用统一尺寸基线并保留区域结构。密集数据可用13px、辅助说明12–12.5px；顶栏按钮32px、状态栏按钮24px是明确例外，不把所有控件强行撑成36px。导航行36px保持既有结构。

## 3. 空间与命中范围

间距以 4px 为基础，允许既有 10/14/18px 关系。页面 padding 28×32，卡片常用 16/18，行间 8/10/12。输入圆角 8、按钮 9、卡片 13、Dialog 16；窗口外角由 [08](08-platform-matrix.md) 的平台呈现场景覆盖。

导航功能图标 20px；按钮图标 18px，普通行内图标 16px；v3 图标按钮 36×36。品牌底座与功能图标分开，见 [07](07-icons-brand.md)。

固定结构：侧栏 216/60、标题栏 36、顶栏 46、状态栏 30、Dialog 480/640、Drawer 420；工具状态列至少 86px。单位均为逻辑像素，不手动乘系统 DPI。

## 4. 动效与层级

颜色/hover 150ms，浮层进入约 200ms，进度宽度 300ms，加载旋转约 800ms。欢迎页的轨道与光点在品牌周围运动，品牌本身不变形、重绘或加材质。装饰动效不承载任务结果。

系统减少动画或应用设置开启时关闭轨道、呼吸、旋转和位移，保留静态进度、阶段文字、错误和焦点。余额低于 $5 时充值按钮允许 1.8s 呼吸提示（产品决策：用户需要随时感知该充值）；减少动画开启时改为静态红色。

基础层级：Drawer 15、Notice 18、Dialog 20、Popover 25、Toast 30、Coachmark 35、画布模拟窗口 40。仅最上层模态可操作；子菜单和 Tooltip 隶属所属浮层，页面不能自行加层级逃逸焦点管理。调试控制在产品窗口外。

Token 修改同步组件页与引用方；按 [10](10-acceptance-checklist.md) 验证可读性与键盘行为，变量存在不是验收证据。

> **皮肤使用边界（v3.1.1）**：晨曦金（亮）与极夜黑金（暗）是品牌默认皮肤；雾青、极光紫仅作个人偏好，**不得用于官方截图、教程、营销素材与 golden 基线**（基线只跑两套品牌皮肤）。新增皮肤属冻结层变更，需产品负责人书面确认。
