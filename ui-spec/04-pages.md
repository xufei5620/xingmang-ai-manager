# 04 · 页面与用户旅程 v3.0

## 新增：游戏加速（2026-09-14）

位于侧栏日常组、画布之后，双栏工作台 T5：左侧深蓝网络球体与线路状态，右侧免费时长圆环及开始/停止主动作，下方本次/累计使用信息。每账号累计 20 分钟，连接成功后开始消耗，停止后保留剩余，不每日重置；额度用尽自动停止。TUN 默认关闭，使用系统代理；用户可在未连接时开启 TUN，覆盖不读取系统代理的应用，连接期间锁定模式。切页/缩到托盘保留连接，退出软件先停止。

未登录提供登录入口；加载、连接中、停止中、失败重试、额度耗尽与线路未开通均有独立状态。未知额度/延迟显示占位，不能显示虚构连接成功或节点。原型入口 `#acceleration` 明确为演示；产品实际节点与额度以后端为准。技术与验证记录见 `docs/GLOBAL-ACCELERATION.md`。

本节定义本轮完整设计的入口、字段和下一步。事件名是原型动作或 UI 意图，不是 API 端点。已有业务证据见 [12](12-github-code-review.md)，G01–G19 接入映射见 [15](15-ui-contract-matrix.md)，状态详情见 [05](05-states-errors.md)。

## 2. 首次使用

欢迎页保留品牌图形/字标与主次按钮：“已有账号，登录”“创建账号”；辅助入口“先看看使用步骤”“减少动画”“帮助”“协议/隐私”。轨道与光点动态装饰可停止，不影响阅读或操作。

欢迎页右侧是星轨场景（v3.1，替代原应用预览模型），与品牌主视觉“星光金方案丙”一致：

- 全幅星空铺满欢迎页背景（canvas，呼吸星、星座连线、偶发流星），页面底部一道地平线光晕；左侧文案、右侧星轨、底部卡片浮在同一片星空上，星轨场景无边框无底板。
- 中心是品牌素材包 `01_矢量标识/无字图形标` 的真矢量星芒（暗色用深底彩色版，亮色用标准渐变版），背后光晕呼吸，向上一道柔光束；中心图形不变形、不加材质。
- 四个工具（Claude Code / Codex CLI / Gemini CLI / Grok CLI）以官方品牌图标胶囊在同一条轨道上等距、同向公转（40s 一圈，2026-10-04 改；原来分内外两圈反着转，会叠在一起），运动中内容始终水平；底部 HUD 显示环境与 Key 同步状态。
- 减少动画开启时公转、呼吸、光束、流星全部静止，星空保留静态一帧；星空与光晕颜色随皮肤（01 §1A）变化，亮色模式自动压低星点亮度。

准备页四步：选一种开始方式 → 准备工具 → 确认连接 → 开始使用。Windows/macOS 优先 Codex 桌面端；Node/npm/CLI 是可选准备。Linux 根据本轮能力场景走 Codex CLI 或直接聊天，不能因没有桌面端就阻塞所有使用。

| 旅程 | 动作与预期下一步 |
|---|---|
| J01 新用户 | 注册校验 → 自动登录 → 准备页；自动登录失败保留用户名并回登录重试 |
| J02 已有工具 | 检测已安装 → 保留已有配置来源 → 确认连接 → 打开；不重复安装或覆盖未知配置 |
| J03 官方用户 | 保留官方来源 → 官方登录状态/额度说明 → 在官方窗口完成登录 → 返回检查 |
| J04 外部安装 | 说明目标系统/工具 → 外部安装帮助 → 我已安装/重新检测 → 成功进入下一步或继续保留帮助 |
| J05 直接聊天 | 登录 → 选聊天 → 首页/聊天；运行环境作为以后可选事项 |
| J06 失败恢复 | 检测/安装/配置失败保留当前步骤 → 重试/检查 → 返回原步骤，不跳到无关工具 |

准备清单只显示适用条件；桌面端可独立使用时 Node 缺失为“可选”，不是失败。部分工具准备失败单列对象和下一步，不能“全部已配好”。

## 3. 首页与工具配置

首页保留工具列表和右侧环境/账号摘要。工具行依次解释工具、版本、来源、当前状态、主动作和更多；用户不需要先理解所有运行时名词。

工具状态拆开：安装、配置来源、官方登录、星芒 Key、运行、可更新、安装任务。主动作按阻塞条件显示安装、准备环境、连接账号、查看密钥、打开、重试或取消，不让一个 configured 布尔掩盖所有状态。

配置弹窗提供五个工具入口（Codex 桌面端、Codex CLI、Claude Code、Gemini CLI、Grok CLI）；字段为账号来源、Key 或手填密钥、模型、工作文件夹。Codex 两入口共用配置，所有来源/Key/模型变化同步；官方模型在 Codex 窗口内选择。

来源必须区分星芒账号、自己填写的星芒密钥、官方身份、已有第三方配置。官方身份按 Provider 为 ChatGPT/Claude/Google，Grok 不提供官方登录选项。unknown 显示解释和处理入口，不自动当作星芒配置覆盖。

保存进入“保留其他设置（推荐）/使用初始配置”。合并只修改目标字段；重置先保留对应备份。保存失败留父表单；成功展示影响对象，运行中的 Codex 可继续到重新打开。配置保存成功与重启失败是两个结果，不能回写成配置未保存。

## 4. 个人中心

九个页签放在左边子导航（160 宽，不跟着内容滚），分三组，每组上面一行小灰字组名：「账号与充值」我的账号、充值与订阅、我的订单、邀请返利；「用量」用量看板、调用明细、异步任务；「密钥与设备」密钥、登录设备。默认打开「我的账号」。上下方向键在全部页签里挪焦点、跨组接着走，回车或空格才打开（手动激活，挪过去不读那一页）；返回上个页面保留入口。详情字段、订单状态机、多账号边界见 [09](09-auth-account.md)。

页头副标题写「当前账号：用户名（邮箱）」，没有邮箱只写用户名，资料没读到写「当前账号的资料暂时没有读到」；右边两颗按钮「切换账号」（打开侧栏同一个切换框）和「刷新」；左上返回箭头悬停写「回首页」。刷新只留页头这一颗：重读账号资料、余额和当前停着的页签，各页签不再各放「刷新」「查询订单」；只刷一块的照旧（余额卡「刷新余额」、「刷新余额与订阅」、「刷新分组」、筛选里的「查询」）。顶部搜索的「切换账号」落在页头这颗按钮上，停在当前页签。

资料和余额分开读。读取中子导航照常显示，右边放和那一页同形的灰色占位块；某页要的那一样一次都没读到，右边正中写「当前账号的资料暂时没有读到」、原因和「重新加载」「联系客服」，不挡用不到它的页（充值与订阅、我的订单、登录设备）。已经读到过、点「刷新」或改了东西以后再读没读到，照旧显示读到的那份（正在改的显示名称不丢），要它的那页顶上出红框，带原因和「重新加载」。各页列表读不到写「订单暂时没有读到」这类一句、原因和「重新加载」，手上有上次读到的也一样，不出顶上的通用红框；红框只留给点了按钮没成功的操作。充值信息和订阅分开读，再读没读到同列表：订阅读不到只影响「我的订阅」「选择订阅」；真读到 0 个支付渠道才说没有渠道，提示放「充值到账户余额」卡最上面，档位、金额和「充值」整块变灰。调用明细、异步任务的筛选第一行只放时间、模型（异步任务放状态）、「查询」「展开筛选」，收着而有条件生效时写「展开筛选 · N」；每页条数放在表格下面翻页旁，不满一页不出现。

账户摘要显示 USD 余额、订阅剩余额度和所属身份，缺失为“—/暂未获取”。官方套餐/额度放在工具官方来源区域，与星芒消费独立。长 Key/订单号/邮箱有复制或可选文本，不挤掉状态。

## 5. 聊天与记录

聊天保持会话列表、消息区与输入区；模型/分组/参数只影响对应会话或请求。发送后显示进行中，停止后保留已返回内容；中文组合输入不得误发送。离线、登录过期、超时、限流、模型不可用、额度不足显示具体恢复入口。

失败消息保留用户输入和可用上下文；重试只创建新的请求尝试，不能重复追加用户消息或重复扣费。账户切换暂停旧账号请求，迟到回包不得污染新账号会话。复制不可用时打开可选文本回退。

记录页按 Provider、搜索、范围、页码筛选；详情 Drawer 保留上下文。归档/恢复必须同时满足 capability 与非只读条件，其他来源只提供可支持的查看/打开动作。无数据、筛选无结果、读取失败分别显示。

## 6. 画布

45-canvas保留独立窗口外壳、项目栏、左节点库、中央点阵图/连线、右侧参数与底部运行状态。入口展示入门示例、最近项目、新建和导入；编辑区有所有项目、保存、运行/停止、连接、撤销、缩放/适应画布与导出。项目只保留在本次演示状态中，保存文案为“已保存到本次演示”。

| 节点type / 名称 | 字段与作用 |
|---|---|
| text / 文本输入 | 通用id/name/x/y与text，填写画面描述 |
| model / 模型处理 | model、instruction，选择示例文字/创意模型与处理说明 |
| image / 图片示例 | size、style，1024×1024、1536×1024、1024×1536参数与主题 |
| result / 查看结果 | 通用字段，运行完成后查看本地构图和输入描述 |

图数据为project.id/name/nodes/edges/updated，edge为起点/终点ID对；selected与参数同步。节点可添加、拖动标题、方向按钮/方向键20px移动、编辑、确认删除；删除清理关联边，撤销恢复节点和连接，保留最近30份编辑快照。画布缩放0.35–1.5独立于主窗口倍率。

连接通过起点/终点选择或点选后继节点建立；缺端点、自连、重复边、循环、结果节点输出或连接到文本节点均给出说明。运行前校验空图、文本/结果节点缺失、空名称/文本、未选模型、未连接输入/后继；错误列表可定位节点。

save.phase为saved/dirty/saving/failed；run.phase为idle/invalid/running/stopped/failed/done。保存和运行时锁定相关编辑，失败保留项目和输入并可重试。回调绑定S实例、canvas45对象、窗口打开状态和操作ID；停止/离开使旧任务失效。运行结果为CSS本地构图，不调用AI、不生成图片文件；size/style仅展示参数，不能声称输出了对应分辨率文件。

离开项目/回所有项目/新建/关闭共用canvasNavigate：运行中先选择继续运行或停止并继续，再处理未保存修改；未保存时可取消、放弃修改或保存并继续。保存失败留在当前图与确认中。A.canvasHasPending()提供dirty或保存/运行中的保护条件；A.canvasCloseThen(callback)在画布保护完成后继续主窗口操作，取消清除callback，S已变化时不执行旧回调。直接关闭画布本身不关闭主窗口。

导出下载format=xingmang-canvas-demo、version=1、project含name/nodes/edges的JSON，不等于真实工程保存。导入粘贴该结构或填入内置示例，新建项目而非覆盖原项目；校验名称、节点类型/ID/坐标/字段、数量及重复/无效/循环连接。格式错误保留文本。

键盘按系统使用Ctrl/⌘ S保存、Ctrl/⌘ Enter运行、Ctrl/⌘ Z撤销、Ctrl/⌘ W关闭。非输入上下文Delete/Backspace请求删除，聚焦节点方向键移动；中文组合输入不触发快捷动作，文本编辑保留原生撤销。Esc先关当前弹窗，再退出连接模式，再遵守关闭保护；弹窗内Tab循环。动作与场景见15，验收CV01–CV05，结果统一见16。

## 7. 外接工具（MCP）

页头添加连接，工具归属筛选、搜索和列表。从上到下是页头 → 工具条 → 自己的列表（卡头「已添加」，读取中、读不到、搜不到都在这张卡里）→「星芒精选」；搜索同时筛精选，一条都不匹配就整张收起。连接检测没跑完时工具条写「这次没检测成」，不写「上次检测」；「重新检测」先重读列表再检测。表单字段包含名称、HTTP/stdio/SSE类型、启动命令或服务地址；网络连接选择无需登录/OAuth/Bearer，本地程序按需填写附加环境变量名与值。高级区按认证类型显示Bearer环境变量名称、OAuth Client ID/Resource。SSE仅在服务方要求时选择；秘密默认遮盖。

行状态区分已启用、停用、未授权、授权中、已授权、已过期、只读。OAuth 登录/退出有返回和失败重试；切工具不把上一工具连接带到下一个。启停/编辑/删除/更新按 capability 门控，失败回退到已确认值，保留草稿。

## 8. 技能与插件

先按工具归属选择，再按我的/工作区/仓库/系统范围筛选。导入字段为来源、目标工具、范围；插件市场保留来源与分支。Provider 与 scope 是不同字段，不相互代替。弹框标题带上工具名（「给 Codex CLI 导入技能」）。技能、插件工具条右边有「重新加载」。

选到不能在这里导入技能的工具（Claude Code、Grok CLI）时，工具条下面平放一行说明 +「看怎么放」（打开教程「技能」篇，只展开那一条补充说明）。插件「已安装」页签先放装了的，再放「星芒精选」；没有插件市场的工具在「市场」页签直说「Gemini CLI 没有插件市场」+「去已安装」，不放搜索框和数量。有新版本时开关左边直接给「更新」。

内置“星芒AI”只读并随应用更新；可用性说明按工具与来源显示，不能给只读项添加卸载。普通技能/插件的启停、更新、卸载与恢复均由 capability 决定。卸载确认列对象和范围，仅真正具备回收恢复能力时提供恢复入口。

## 9. 备份与安装卸载

备份按工具列文件清单、时间、类型、大小与校验状态；预览内容脱敏。当前设计范围：Claude settings.json；Codex config.toml/auth.json；Gemini settings.json/.env；Grok config.toml。这些是本轮映射，真实文件路径和读取白名单需适配实际平台，不任意扩大为整个目录。

恢复：预览 → 明确覆盖对象 → 保存当前快照 → 校验 → 应用 → 回读验证；失败保留原数据/快照，并区分未写入、部分失败、恢复未完成。备份删除只删除选中备份，不借机清理目录。

安装卸载页分运行环境与工具。Windows托管安装；macOS/Linux按能力提供外部安装后检测。Codex桌面端不要求Node，CLI依赖检查单列；Python不写成Gemini固有前置。安装可取消阶段和不可中断阶段明确；卸载不能统一承诺只删程序或都可恢复。

安装卸载页的「工具」「运行环境」两张表每行和表头同一套三栏：工具约四成（图标单独一格，名字和厂商上下两行），版本与状态约三成（先版本号再状态标签，检测失败的原因另起一行），操作约两成半（主按钮在左，「…」贴最右）；没装的写「—」「未安装」，Node.js、Python 用自己的标志。正在装的那一行写「安装中」，按钮转圈带百分比（没有百分比时只转圈、字照旧），名字下面换成首页那种大白话进度，有百分比时行底加一道细进度条；在这一页点的安装才有「取消」，点了写「正在停止」；别的行按钮灰着，鼠标停上去写「等 Gemini CLI 装完再操作」（工具名照正在装的换）。没装上的那一行写红色「安装失败」，名字下面是页顶红框领头的那句（比如「写不进安装目录」），红框换了说法就不再挂着。整页读不到工具状态时各行中间只写一次灰字「暂未读到」、不放标签，右边不放「重新检测」和「安装」（「…」照旧），整页只留页头和红框两颗「重新检测」。「安装日志」没有日志时不出现，装命令行工具或 Codex 桌面端时一有日志就出现、装完留着（Node.js、Python 的安装不写日志），最高约 8 行，多了在卡里滚，停在最底下时跟着新的一行走。「查看安装步骤」「安装指南」打开装它的那一章：Codex 桌面端在 Mac 上去「Mac 上装桌面端」、别的电脑去「Codex 桌面端怎么安装？」，命令行工具去「进阶：安装与使用命令行工具」，运行环境在 Mac 上去「Mac 上准备 Node.js 和 Python」、别的电脑去命令行工具那一章。

备份页按工具筛选时，空状态点名那个工具（「Gemini CLI 还没有备份」），全空时说明「改工具配置前会自动留一份。想现在就留一份，点下面的按钮。」；「创建第一份备份」和右边「马上备份」卡的下拉都跟着上面的筛选走，选「全部工具」时不动。搜索框写「搜索日期」，按列表上显示的字（「今天 14:20」「10月2日」）和鼠标停上去的完整时间搜，不再按看不到的备份编号搜。主按钮「创建备份」在右边「马上备份」卡里，和选工具放在一起，是 T1「主按钮永远在页头右侧」的例外。每行的工具图标单独一格。

## 10. 检查、反馈、教程与更新

检查只运行适用项，逐项显示完成、可选、待处理；停止保留已完成结果。“去处理”打开准确页面/字段，再提供返回检查重新验证。结果排在「连接自检」「Codex 干活检查」两张卡上面，按待处理、需留意、正常排，正常的默认收成一行「另外 N 项正常」+「展开」；页头放「导出检查报告」和「重新检查」。从设置的「去检查页」、开机提示的「去看看」进来时滚到对应那一项或第一项问题。连接自检一个工具一行（工具名、小标「正常 / 有问题 / 没测成」、一句结论；没配的工具照旧是灰色「未配置」，不算问题），有问题的排前，第二句收进「查看详情」。

反馈区可预览、复制、导出同一脱敏报告，区分当前日志与报告内容；清空运行日志先说明对象。报告生成不自动发送客服；复制失败提供手动文本，导出失败保留预览。「报告会自动脱敏」是页头下面的一行细条（左边小盾牌，最右文字按钮「联系客服」）。运行日志卡头左边「运行日志」+ 灰字「共 N 条」（只取了最近一部分时写「最近 500 条」），右边「打开日志目录」和红字「清除日志」；没读到或没有日志时「清除日志」点不了，读不到时说明「点「重新加载」再试；还不行，点「打开日志目录」直接看日志文件。」。日志一条一行：时间（今天只写「20:02:54」，更早写「10月2日 18:02:54」）、固定宽的级别字（「错误」红、「提醒」橙、「信息」灰）、内容（太长打省略号）、灰字来源、最右「详情 ›」，整行点开详情框；先显示最近 100 条，最后一行「再显示 100 条」，换了筛选条件从头 100 条。

教程左目录、搜索、右章节与步骤保留；关键词命中标题/正文，搜索时滚到第一处命中，清空搜索回当前有效章节（细节见 `25-illustrated-tutorial`）。跳转配置或安装返回原任务，缺工具时先提示安装步骤。

更新统一驱动页面、状态栏与通知卡：检查、最新、可用、下载、下载完成、失败/取消。重新检查与重新下载动作不能混淆。安装前确认已保存任务，失败保留当前版本与手动恢复入口。更新页卡片里「当前版本」不带图标、和下面几行左对齐，版本号用正文的字号和颜色；有新版本时下面多一行「新版本」（退回旧版本时没有这一行）。读不到时卡片标题写「更新状态暂未读到」，还在读时照旧「正在读取更新状态…」。「安装前需要知道」不折叠，在更新说明下面隔一道细线直接写。人在更新页时，「正在下载更新」「下载更新失败」「新版本 X 可以安装」三种气泡不弹（页面上写的是同一件事），离开更新页照旧弹；其余几种照旧。

## 11. 设置八项单面板

未登录时也能在线路设置自救：登录、注册、找回密码的表单提供「切换连接线路」，在同一个 Dialog 内展示设置页同款线路面板；关闭面板返回原表单，保留已输入的账号、密码和验证码。保存失败保留确认值，保存期间不允许离开面板；仅手动点击「现在重开」才进入原生重启检查，取消重启继续保留表单。首次向导的「登录账号」也能到达此入口。

网络增加「星芒账号线路」和「历史账号线路」：前者只提供注册表内的默认线路 / 备用直连，后者目前只有默认线路。沿用 SettingRow + Select；保存失败保留原值，保存中禁用线路控件，保存成功只表示下次启动采用。已保存值与主进程本次启动值不一致时显示 Notice「线路已保存，等待重启」和「现在重开」，切换分页后仍保留提醒；重开继续经过已有未保存工作和运行任务保护。切换线路不切换账号，不跨站点共享凭据。

外观、启动与关闭、工具、网络、通知、账号、隐私与数据、更新与关于。左侧二级导航一次只渲染选中项的内容，不把八组堆成滚动长页；右侧内容长时只有右侧滚，左侧组名停在原处。

每一行的 id、标题和常用说法登记在 `registry/business.ts` 的 `settingsItems`：设置页的行标题和顶部搜索读同一份，每行带 `data-anchor` 供搜索直达。2026-10-04 起：「启动时检查新版本」「自动更新」挪到「更新与关于」（「更新」页也能直接开关，改的是同一份设置）；「通知」里九个分类放在小标题「提醒哪些事」下，总开关关着时标题旁说明「桌面通知关着，下面这些都不会提醒」；「账号」新增「切换账号」；「网络」新增「企业证书」（去检查页并翻到「安全证书」那一项）。

外观可立即预览；其他逐项保存：正在存时组名右边写「正在保存更改…」，存好了弹会自己消失的小提示（字照旧，如「已保存」「通知偏好已保存」），页面不往下跳；没存上照旧在页顶出红条；带「打开所在位置」的导出结果照旧在页顶。要先读系统状态的行，读的时候开关灰着不写字，没读到写「暂未读到」并在红条右边给「重新读取」，只有这台电脑真的不支持才写「此版本暂不支持」。开关失败回退已确认值，文本失败保留待重试草稿。不同字段独立保存，同一字段最新写入获胜；新账号/页面不得接收旧操作成功提示。系统设置显示生效范围，原生权限和重启条件由真实适配结果决定。

数据迁移/回滚保留前后快照；回滚不删新版数据。导出/清除说明范围、敏感信息与后果；原型的示例清单或确认预览不能当作真实完整导出/清除完成。
