# 19 · 扩展手册：以后加功能怎么做

这套 UI 是**固定的**。以后任何新页面、新按钮、新工具、新设置，都按本手册走，不许绕过。原则只有一条：**先改原型，再改代码；先用现有零件，再考虑新零件。**

## 0. 通用流程（任何 UI 改动）

```
需求 → ① 在原型里加出来（work/modules/ 新模块或改现有模块，重建 HTML）
     → ② 截图进 prototype/previews/，更新对应 md（04 页面 / 02 组件 / 05 状态 / 06 文案）
     → ③ 产品负责人对着截图确认
     → ④ 代码实现，PR 附「原型 vs 实现」对照图
     → ⑤ 更新 golden 截图基线（23）
```
跳过 ①② 直接写代码的 PR 一律打回。

## 1. 加一个按钮

先问三个问题：
1. 它是这张卡 / 这一行的**主动作**吗？主动作只能有一个（`btn-primary`），已经有了就只能是 `btn-secondary` / `btn-ghost`，或者收进 `···` 菜单。
2. 它是**危险动作**（删 / 卸 / 撤销 / 清除）吗？用 `btn-danger`，放 `···` 菜单最后一项，必须过 Confirm。
3. 它出现在**列表行**里吗？列表行只有两个动作槽：附加动作槽（72px，可空）和主按钮槽（92px）。第三个动作进 `···`。

文案：动词开头，≤ 6 字，查 `06 §2`。图标：查 `22 §3` 语义表，没有的先登记。

## 2. 加一个页面

1. 在 `21-page-templates.md` 五个模板里选一个（列表页 / 设置页 / 详情抽屉页 / 向导页 / 双栏工作台）。选不出来 = 需求没想清楚，回去拆。
2. 导航位置：日常（每天用）/ 加能力（给 AI 加东西）/ 维护（不常用）。放「更多」里的页面必须能从命令面板和帮助面板到达。
3. 必填：页头 H1 + 一句 lead（≤ 64 字，说「这页干什么 + 什么时候来」）、空态（标题 / 说明 / 一个按钮）、加载态（骨架）、至少一个失败态。
4. 登记：`04-pages.md` 加一节；`03 §3` 侧栏结构更新；命令面板「跳转」组加一项；`22 §1` 页面注册表加一行（id / 标签 / 图标 / 分组 / testid）。
5. 平台差异：某平台不可用时**隐藏**入口而不是禁用（Codex 桌面端在 Linux 的做法）。

## 3. 加一个 AI 工具（第六个厂商）

**不改任何页面代码**，只往工具注册表加一条（`22 §2` 的 schema）：id、名称、公司、品牌图标（`@lobehub/icons` 组件名）、安装方式（npm 包 / 桌面安装器 / 外部）、依赖（node / python / 无）、配置文件路径、Key 写入方式、支持的来源（星芒 / 官方 / 手填）、模型列表接口、快捷键位次。

登记后自动出现的位置：首页工具列表、向导第一步选项、配置弹窗页签、外接工具 / 备份的工具分段、命令面板、托盘菜单、快捷键 ⌘N。
需要人工补的：`06` 术语表加名称、`07` 确认 lobehub 有图标（没有则走 simple-icons，再没有则用首字母底座并在 PR 里标记）、教程页一段。

## 4. 加一个设置项

1. 归到九组之一；找不到组 = 不加。
2. 用 `setting` 行：左「标题 + 一句说明（写开了会怎样）」，右控件（开关 / 分段 / 下拉 / 按钮）。
3. 即时生效 + toast「设置已保存」；不即时的必须在说明里写「重启后生效」。
4. 主进程要读它的，在 `08` 平台矩阵加一行说明三个平台各怎么实现。

## 5. 加一个弹窗

先看能不能不弹：只读信息 → toast 或告警条；查看详情 → 抽屉；不打断的提醒 → 通知卡。确实要弹：
- 用 `dialogShell`，480 或 640 两档，不许自定义宽度。
- 结构固定：图标 + 标题 + 副标题 / 内容 / 底部（左次要链接、右取消 + 主按钮）。
- 首焦落在第一个可操作项；Esc 关闭；有草稿时点遮罩不关。
- 登记到 `04 §18` 弹窗清单。

## 6. 加一种状态 / 一种错误

1. 查 `22 §4` 状态词表有没有；有就复用词和颜色。
2. 新状态必须同时定义：胶囊文字、颜色（只能 ok / warn / bad / accent / 默认）、出现位置、对应动作按钮。
3. 错误必须回答三句：发生了什么 / 对我有什么影响 / 点哪里。登记到 `05` 和 `22 §5` 错误映射表。

## 7. 加一个账号页签 / 公告类型 / 通知类型

- 账号页签：加在九个之后，`04 §17` 登记；表格用 `table` 组件，筛选用 `toolbar`。
- 公告类型：只能是 promo / warn / info 三种之一，不新增颜色。
- 通知类型：设置「通知」组加开关；只在软件在后台时发系统通知，前台改 toast / 通知卡。

## 8. 加一种视觉样式（最后手段）

写新 CSS 之前必须证明：现有 16 个组件 + 5 个模板拼不出来。证明成立 → 先在 `02` 登记为第 17 个组件（结构 / 尺寸 / 状态 / 边界），加进组件检阅页，再实现。**页面私有样式永远不允许。**

## 9. 禁止清单

- 新颜色、新字号、新圆角、新阴影（只能用 `tokens.css`）
- emoji、手画的品牌标、第四套图标库
- 「确定 / 提交 / 操作 / OK」按钮
- 一张卡两个主按钮
- 弹窗套弹窗
- 响应式断点（版式固定 1280，见 03）
- 在业务代码里写 `process.platform` 判断（只能在 `electron/platform/`）
