# 17 · 托盘余额与紧凑菜单修订 v3.0.1

2026-09-06。用户指出托盘菜单不如旧版，并明确要求保留最初版本的余额显示。本次只修订托盘，主界面大布局及其他业务页面保持v3.0设计。

## 修正

- 保留顶部品牌与余额位置。已登录显示当前账号余额；未登录显示“登录查看余额”，不再把整个入口隐藏。
- 余额未知显示“—”，不伪造为0；账号余额变化后同步刷新。
- 保留打开星芒、已安装工具、充值、检查更新、设置、退出的原顺序与分隔线。
- 托盘独立挂载在主窗口外，为其同步主题、操作系统和高对比状态。浅色菜单使用白底，深色菜单使用品牌深蓝底，Logo与文字随主题一致。
- 保留紧凑单列，宽272px、正文13px、菜单行32px、图标16px；小窗口内部滚动，不扩大为信息卡片。
- 补上下键、Home/End、Enter、Escape和返回焦点；Linux无托盘时继续保留主窗口路径。

## 证据与边界

`work/modules/97-check.cjs`以可编辑源码生成独立托盘组件夹具，15项检查通过，覆盖三平台两主题、余额/未登录/未知/刷新、充值及工具跳转、键盘、主题切换、无托盘降级和小窗口。无脚本错误或HTTP请求。截图见`qa/tray-v3.0.1`，检查结果记录同目录。

此测试没有访问用户正在打开的标签页，也没有调用原生系统托盘。当前内置浏览器对file://页面的自动读取被URL策略阻止，因此没有把用户当前页面或三平台真机状态称为已验证。独立组件截图已经人工检查。

16与qa/v3-results保留v3.0基线的13组结果及基线文件散列，不冒充v3.0.1整包重新执行结果。本次补丁的源码散列、单文件原型散列和压缩包校验见随包交付记录。旧v3.0压缩包保留，新交付包使用v3.0.1文件名。

后续规范：托盘外观和账户余额属于独立验收项，不能只检查“菜单能打开”便视为通过。未登录状态不显示虚构余额，应提供明确的登录入口。
