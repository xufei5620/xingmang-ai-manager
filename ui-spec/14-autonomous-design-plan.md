# 自主递进设计计划

用户要求：保持大布局，面向小白优化与美化；动态科技感欢迎页；完整引导、跳转、组件、功能与规范；自主完成多轮检查。工作范围是独立原型及素材，业务演示不连接真实服务。

## 不变项

- 主窗口标题栏、216/60侧栏、顶栏、内容、状态栏五区及1280设计宽。
- 首页工具列表、右侧环境/账户区；其他页面沿用现有结构。
- 星芒品牌图形和Starlight Gold主题；侧栏字标32px、托盘16px专用母版。
- 设置八项二级导航一次只显示一组；折叠侧栏账号区域完整可操作。

## 文件协作

`work/prototype.js` 保留已有基础；新增功能按 `work/modules/` 分域维护，构建时依顺序内联成一个离线HTML。`00-runtime.js` 提供状态与统一反馈；`10-onboarding.js/css`、`20-account.js/css`、`30-extensions.js/css`、`40-tools.js/css`各有单一负责人。运行时不依赖模块网络加载。

每个模块必须列出拥有的渲染函数与动作，不能相互覆盖。每轮先复现未满足的要求，再实现和验证；发现回归后修复并复跑相关检查。当前GitHub行为依据固定提交0c9ec4a，代码证据见12，最终将逐条更新对齐状态。
