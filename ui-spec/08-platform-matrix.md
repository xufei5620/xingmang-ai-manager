# 08 · Windows / macOS / Linux 平台矩阵 v3.0

三平台都属于本轮设计范围。以下11个版本与5个Linux会话来自 `50-platform.js`，用于代表性呈现和能力替代流程；不等于已在这些系统安装运行，也不构成工具或安装包的系统支持承诺。源码能力基线见 [12](12-github-code-review.md)，真实接入检查见 [10](10-acceptance-checklist.md)。

|---|---|---|---|
| win10 | Windows 10 · 22H2 | 直角、独立标题栏 | — |
| win11 | Windows 11 · 24H2 | 8px小圆角 | — |

## 2. Linux 会话

| 场景ID | 协议 | 托盘 | 通知服务 | 替代路径 |
|---|---|---|---|---|
| x11-tray | X11 | 有 | 有 | 正常窗口/应用内入口同时保留 |
| wayland-tray | Wayland | 有 | 有 | 定位、聚焦与部分最小化由合成器决定 |
| x11-no-tray | X11 | 无 | 有 | 关闭保留窗口和任务栏；明确退出才结束 |
| wayland-no-tray | Wayland | 无 | 有 | 同上，保留系统窗口操作 |
| x11-no-service | X11 | 无 | 无 | 保留窗口，结果通过应用内提示展示 |

不能仅凭GNOME/KDE或系统版本推断托盘/通知可用。没有托盘不静默退出，也不提示“已缩到托盘”；安装桌面扩展不是完成基础使用的必经步骤。

## 3. 安装与开始方式

| 能力 | Windows场景 | macOS场景 | Linux场景 |
|---|---|---|---|
| Codex桌面端 | 应用内管理安装 | 外部安装后检测 | 当前能力场景不提供，转CLI/聊天 |
| Node.js | 应用内管理安装 | 外部安装后检测 | 外部安装后检测 |
| 其他运行环境 | 按工具需要检测；Windows可用路径才管理安装 | 外部安装说明 | 外部安装说明 |
| CLI | 按依赖/版本/权限检测后安装或打开 | 同左，环境路径单独处理 | 同左，架构/终端/发行包单独处理 |
| 首次引导 | 桌面端优先，CLI环境可选 | 桌面端优先，保留外部安装返回 | CLI或直接聊天，不阻塞整个应用 |

桌面端不以Node为前置；Python不作为Gemini固有依赖。外部安装按钮只提供步骤与返回检测，不点击即成功。安装取消、失败、清理与恢复能力由实际安装器返回，不能只按平台名称假定。

## 4. 字体、路径、键盘和窗口

| 项目 | Windows | macOS | Linux |
|---|---|---|---|
| 字体 | Segoe UI/微软雅黑UI | 系统/PingFang | Noto Sans CJK SC等回退 |
| 修改键 | Ctrl | ⌘ | Ctrl |
| 命令面板 | Ctrl+K | ⌘K | Ctrl+K |
| 工作路径样例 | D:\projects | ~/Projects | ~/projects |
| 应用数据样例 | %APPDATA%\xingmang | ~/Library/Application Support/xingmang | ~/.config/xingmang |
| 终端 | Windows Terminal→PowerShell→cmd，按实际检测 | Terminal.app；iTerm2只在已装时可选 | gnome-terminal/Konsole/xterm等按检测选择 |
| 标题栏 | 右侧系统按钮 | 左侧红黄绿；⌘W关窗口/⌘Q退应用 | 系统/客户端装饰由会话适配 |
| 窗口恢复 | 检查工作区与多屏 | 检查Dock/菜单栏与多屏 | Wayland不承诺任意定位 |

路径是展示样例，真实配置文件由每个Provider适配器提供；不硬编码demo用户或把所有工具套用同一路径。缩放唯一算法见 [03](03-layout-window.md)，窗口DIP、系统DPI与最终倍率分开记录。

## 5. 系统能力与回退

| 能力 | UI契约 | 原生集成证据 |
|---|---|---|
| 托盘/菜单栏 | 可用时按偏好隐藏，始终有返回入口；不可用保留窗口 | 图标、点击、菜单、退出、二次启动 |
| 通知 | 权限阻止/服务缺失时应用内Notice与状态页 | 权限、勿扰、送达/点击、账号与任务归属 |
| 深链 | 解析失败给原因，未知页面不跳错；支付回跳只触发查询 | 注册、冷/热启动、单实例转发、来源校验 |
| 开机启动 | 显示saving与真实结果，失败回退 | 用户级/包形态/系统登录项与卸载清理 |
| 文件/剪贴板 | 取消保留父草稿，复制失败给可选文本 | 原生对话框、权限、portal、文件读写结果 |
| 代理/证书 | 标明作用范围，保存与连接测试分开 | 应用与工具进程分别核验，不能承诺覆盖全部请求 |
| 凭据保存 | 默认遮盖、报告脱敏 | 平台安全存储可用性及降级行为 |
| 主题/动画 | 当前深浅、高对比、减少动画可见 | 系统事件与应用设置优先级 |

## 6. 真机验收记录

每条记录包含系统完整版本、架构、Linux会话/桌面、包格式、应用提交、操作步骤、能力检测值、实际结果、回退结果和证据。主应用自身打包格式、签名、公证、更新方式按实际仓库与发布产物核实；本原型不冻结NSIS/DMG/AppImage等方案。

设计模拟验收与真机记录分栏。未获得真机证据时写“未做真机验证”，不把它算作离线原型缺失，也不能升级为产品兼容通过。
