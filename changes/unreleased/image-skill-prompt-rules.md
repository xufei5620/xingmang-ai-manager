## 用户

- 在 Codex、Claude Code 中画图时，简短的描述会先补全画面细节再出图，回复中附上所用的描述；需要修改图片但未提供图片文件时，会先请您提供图片。

## 开发

- 画图技能 `SKILL.md` 加「写描述」一节（yoyo 11-27「技能写描述」，含画图优化需求 B2「没有图片路径时先问」、E2「改图怎么写描述」「不追问客户没提的参数」两处文案）：具体的照原意整理、笼统的才补场景/构图/光线/风格，不加客户没提的人物、品牌、标语、配色，图上的字一字不改，按原话画就原样用；改图只写要改的地方并写明其余不变；只在缺图、缺客户专属文字、没说画什么时问一句；「完成后」附上这次用的描述。`mcp-server.mjs` 的工具说明和 `prompt` 参数说明带上短版。思路参考 OpenAI Codex 的 imagegen 技能（Apache-2.0）和 shinpr/mcp-image（MIT），没有照搬原文。技能文件靠清单里的旧摘要自动更新，客户改过的不覆盖。
