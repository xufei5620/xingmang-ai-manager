# 07 · 品牌 Logo 与图标

v3.0。星芒品牌引用 [brand](brand/README.zh-CN.md) 原素材，保留中文索引。界面图标来自 `work/modules/60-icons.svg` 与 `61-icons.svg` 的 Lucide 0.468.0，共 53 个内联符号；几何与许可证随资源保留。中文全套素材可从交付包根目录的“品牌素材（中文）/点这里开始.html”浏览。

## 1. 分工

| 用途 | 来源 |
|---|---|
| 星芒品牌 | 原品牌 SVG/PNG，按对应母版使用 |
| AI 厂商与模型 | 既有厂商品牌；后续可接入 @lobehub/icons，包版本及导出先查实际仓库 |
| 运行时、支付、浏览器、系统标识 | 既有品牌资源；Simple Icons 仅在资源与许可核对后作为接入来源 |
| 动作与导航 | 本轮 53 个 Lucide 符号，currentColor，同一含义复用 |

不使用 emoji 替代图标，不手画第三方 Logo。彩色品牌保留原色；单色品牌按资源约定展示。资源缺失保留可读文字，不伪造厂商图形。示例包名与模型名不代表依赖已安装或模型可用。

## 2. 星芒品牌

| 位置 | 本轮规则 |
|---|---|
| 展开侧栏 | micro32 图形高 32px + 中文 AI 字标高 32px |
| 折叠侧栏 | 保留 32px 图形，隐藏字标，展开动作可达 |
| 欢迎页 | 图形与字标均高 32px；主标题和动态轨道独立布局 |
| 闪屏 | 保留 symbol 132px + 字标 28px 布局 |
| 标题栏 / 关于 | 按已有资源 20px / 32px |
| 16px 托盘 | micro16 专用母版，不把 micro32 缩小替代 |
| 32px 托盘 / 高倍率 | 对应 micro32；macOS 模板遵循系统单色要求 |
| 应用图标 | 原母版生成并核验 ICO/ICNS/PNG，原生接入另记证据 |
| 默认头像 | 中文首字或通用头像，不重复使用 Logo |

深底使用适用 dark/white 变体，浅底使用 standard/navy 变体。构建通过现有资源映射引用，不把资源文档目录当成安装产物路径。

不拉伸、旋转、改色、裁去星轨或小星；不与厂商标识拼接；不加玻璃、金属或辉光材质。安全留白至少为图形高度 1/8。欢迎动画位于品牌周围，不能改变原图形。

## 3. 功能图标尺寸

| 场景 | 主应用 v3 |
|---|---|
| 主导航 | 图标 20px、字 14px、行 36px、gap 10px |
| 导航附加箭头 | 16px |
| 按钮、快捷动作 | 18px |
| 输入、普通行内、命令触发 | 16px |
| 品牌/工具行底座 | 通常 36px，不套功能图标描边 |
| v3 图标按钮 | 命中范围 36×36px，图形 18px |
| 空态 | v3 登记 30px；基础空态 28px，按实际变体标明 |

保持 Lucide 原几何，主应用描边覆盖约 1.75；图标与文字居中，不按页面任意放大。

安装用下载符号，更新用循环箭头，配置用设置，删除/卸载用垃圾桶但文字区分后果，帮助用问号，公告用铃铛，密钥用 Key。独立画布加外部窗口标记。纯图标按钮有独立可访问名称；Tooltip 不是唯一标签，装饰 SVG 对辅助技术隐藏。

验收核对所有 use 引用、两主题、禁用可读性、折叠侧栏、16/32px 品牌清晰度；通过结果统一见最终验证记录。


主原型追加 Link 与 Play 两个同源 Lucide 图标，见 work/modules/61-icons.svg；组件检阅页内联51个子集。全部采用同一24网格、1.75线宽，品牌图标不计入UI图标数量。
