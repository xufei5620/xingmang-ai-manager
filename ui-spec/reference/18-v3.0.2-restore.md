## v3.0.3 落实的两项产品决策（2026-09-06 拍板）

| 决策 | 结论 | 原型改动 |
|---|---|---|
| 首次引导推荐哪个工具 | **不偏向任何一方**：展示全部工具，用户自选 | 第一步六选一：Claude Code / Codex CLI / Codex 桌面端（Linux 不显示）/ Gemini CLI / Grok CLI / 先聊天，无「推荐」标签，未选时「下一步」禁用；Gemini 路线多一小步 Python |
| 注册后 Key 从哪来 | **服务端自动建齐 4 把**（Claude / Codex / Gemini / Grok） | 登录后本机自动持有 4 把 Key；已安装且来源为星芒账号的工具自动写入对应 Key；向导第三步显示「已自动写入，不用手动配置」；密钥页直接列出 4 把 |

真实接入契约：注册成功 → 服务端在 `POST /api/user/register` 事务内创建 4 把 Key（命名「〈工具〉· 本机」，分组按后端默认）；登录后 `GET /api/token/` 拉取，客户端按工具名匹配写入；缺少任何一把时客户端不自建，显示「服务端未准备好这把 Key」并给「重试同步」。
