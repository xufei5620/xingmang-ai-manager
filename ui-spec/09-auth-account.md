# 09 · 认证、账号与付费 v3.0

用户界面与交互模拟由10-onboarding、12-recovery、20-account及40/85协作提供。真实业务的固定源码证据见12；本节规定 UI 字段、状态和接入约束，不新增或猜测API端点。

## 1. 认证与找回

登录字段：账号、密码、必要的记住选项与错误说明。注册字段按实际表单给出账户、邮箱、密码/确认及协议；输入错误紧邻字段，提交失败保留内容。注册成功先自动登录，失败才回登录并预填用户名；账号创建、登录、初始化各自记录结果，不承诺注册时已创建全部Key。

找回分三步：获取邮件→粘贴重置码→取得新密码。字段为注册邮箱、原始粘贴内容、解析后的token/来源类型、发送/重置/复制阶段与返回登录上下文。邮件请求用中性文案，不显示邮箱是否已注册；示例冷却60秒，真实冷却由认证契约提供。支持直接重置码或HTTP/HTTPS链接的唯一token参数；空值、空白、无token、多token和无效协议给具体错误，不打开粘贴的外部链接。过期码需重新获取，发送/重置失败保留输入。成功结果默认遮盖，实际剪贴板成功后才提示；失败可手动选中复制。返回原登录页预填邮箱、清空密码，父流程与旧异步回包受流程ID保护。

认证嵌入配置/聊天子流程时，成功回父流程并仅更新对应身份；取消保留父草稿。目标账号重登录失败保留当前已登录账号，不提前替换。

## 3. Key字段与状态

Key编辑表单：名称、分组、额度模式（无限/自定义）、自定义USD额度、到期模式（不限/指定日期）、日期。自定义额度必须大于0；指定日期完整有效；服务端最终规则与状态优先。Key展示默认遮盖，启用状态可临时显示，30秒后自动隐藏；显隐回调绑定选中对象与当前流程，不影响其他账号。复制仅操作选中对象。

状态 active=启用，disabled=已停用，expired=已过期，exhausted=额度用尽。停用说明使用它的工具会受影响并可再启用；过期或耗尽分别给出修改日期/额度入口，不统称撤销。

配置→新建Key成功后，仅把新Key回填原工具父表单；父来源、模型、工作目录、页签与草稿保留。用户选择仍可用Key才允许保存星芒来源配置。Codex CLI与桌面端共用选择。

## 4. 余额、官方额度与扣费

星芒账户余额、订阅余额、Key限制、官方套餐各自独立。账户金额展示USD两位；调用小额4位，极小非零费用最多6位；未知为—。不能照搬演示种子的null转0逻辑处理真实服务数据。

官方区域显示身份、套餐、订阅续期renewal、可用重置次数resets、窗口标签/剩余百分比/重置说明；未获取字段显示“尚未获取”。刷新loading/error与官方登录状态分开，额度读取失败不等于工具不能打开。官方模型在官方工具内选择，星芒余额不控制其可用性。

四种扣费偏好：

| 值 | 文案与顺序 |
|---|---|
| subscription_first | 优先订阅；订阅不足时按允许策略使用余额 |
| balance_first | 优先余额；余额不足时按允许策略使用订阅 |
| subscription_only | 仅使用订阅；不足时提示订阅，不自动花余额 |
| balance_only | 仅使用余额；不足时提示充值，不自动花订阅 |

有效订阅按状态、到期与剩余额度过滤，多条订阅分别显示。原型的分摊结果可为balance/subscription/mixed；真实扣费和不足判断由权威服务结果决定，前端预估不能作为结算证明。

## 5. 报价与订单

充值输入与渠道来自同一快照；渠道列包含可用性、适用充值/订阅、最低金额和币种。服务未返回可用渠道时显示明确空态，不能仍提供下单。原型渠道名/价格为示例，不固定生产方式或价格。

报价UI字段：quoteId、owner、充值/订阅类型、原始金额、折扣、实付金额、币种、渠道、到账USD或订阅权益、过期时间。确认页→返回修改保留选择；过期重新获取；换账号、渠道失效或计划额度变化后重新核验。

订单UI字段：orderId、owner、类型、创建时间、报价快照、状态、查询次数、结算标记与时间。事件为创建订单、关闭付款页、继续查询、接收查询结果、返回充值；不是客户端伪造回调到账。

状态 pending等待付款 → querying正在查询 → paid已到账 / failed付款失败 / unknown待核实 / timeout超时待核实。关闭付款页不删除订单，重新进入我的订单继续查询。超时不自动等于未付款；明确“先继续查询，避免重复付款”。重复已支付结果只结算一次。

URL或POST表单支付方式按真实能力适配，回跳只触发核实。延迟结果必须归属下单账号，切换到其他账号时不增加其余额或弹出错误归属提示。

## 6. 订阅、邀请与设备

订阅购买展示价格、总额度、有效期、购买次数上限、已买次数；账户余额和在线支付分开，待付款订单也计入占位判断以避免重复下单。余额不足提供在线支付/充值；完成后新增订阅并保留订单。过期/耗尽订阅仍可查看，不能提供额度。

奖励转入表单校验大于0、不超可转入奖励、最多两位小数；确认后属于当前账号，订单或流水可追踪。邀请复制失败提供可选文本，不假称已复制。

撤销设备说明目标设备需重新登录；当前设备不使用普通行撤销动作。退出其他设备保留当前设备，列表更新只有在真实成功后执行。

## 7. 多账号与异步隔离

多账号是本轮新增UI设计。每账号隔离user、keys、orders、usage、tasks、devices、chat、subscriptions、preference、页面草稿和请求归属；真实存储必须使用稳定账号ID，不能以显示名作为唯一身份键。

切换前保留当前快照，验证目标登录态；目标过期可取消或重登录，当前身份不丢失。切换成功后仅同步使用星芒来源的工具，官方/手动/unknown来源不被强行切换。逐工具失败显示部分同步及具体工具，不能提示全部成功。

旧账号聊天请求停止或失效，迟到回包与订单查询按owner更新所属数据；不能进入新账号界面。退出保留可重新登录恢复的订单/资料，清空当前可见敏感列表与会话。凭据安全存储、会话隔离、设备撤销与服务结算属于真实接入验收；离线UI合同已在本轮设计。
