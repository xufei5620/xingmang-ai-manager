# 界面改版 v4.0 草案

**状态：草案。** 这一版是产品负责人（yoyo）在 2026-10 的改版会话里逐项看过、拍过板的可交互原型，**还没有取代现行的 v3.1.1 规范**。
`src/renderer-v2/` 照旧按 `ui-spec/prototype/星芒AI管理工具-可交互原型.html` 和 01–24 号文档实施；要按这一版改界面，先另起 `spec:` PR 把它并进正式规范（按 [23 治理](../23-governance.md)，配色和窗口版式属于冻结层，要升主版本号）。

## 怎么看

用浏览器直接打开 [星芒AI管理工具-改版原型.html](星芒AI管理工具-改版原型.html)。单文件，离线能用；字体从 Google Fonts 取，断网时退回系统字体。

窗口上方的检阅条可以切换：视图（界面 / 组件规范）、配色、系统（Windows / macOS）、窗口尺寸、账号情况、账号来源（星芒账号 / 历史账号）、工具状态、网络。
检阅条，以及界面里写着「原型」的灰色小按钮（填入示例、模拟支付结果、示例数据说明），都只是原型用的，不进产品。

## 已拍板的决定

- 配色只留两套：黑金深色、晨曦金浅色。
- 正文 14px。
- 金色只用在主按钮、选中、焦点和金额上；浅金按钮只给充值、购买和需要注意的事。
- 说明文字能省就省。
- 首页的工具按厂商排成卡片，不做筛选和搜索。
- 每个工具的配置弹窗只管这一个工具；Codex CLI 和 Codex 桌面端共用一份配置。
- 设置左侧的分组名一律四个字。
- 「退出登录」「切换账号」放在个人中心的账号概览里。
- 不支持 Gemini CLI。
- 画布不在这次改版范围内。
- 工具和支付渠道前面的字母方块是占位，正式版换成品牌图标。
- 960 × 560 最小窗口时，界面缩放最低到 90%。
- 充值档位、赠送、价格、最低额和支付渠道都从当前账号的站点读，界面不写死。两个站现在都是 1 元到账 1 美元；原型里的档位、最低额和渠道是示例。
- 付款在星芒自己的支付窗口里完成，到账、超时、失败由星芒去查，不让客户回来点「我付好了」；订单不能取消，也没有「继续支付」（站点没有这两样）。
- 历史账号（另一个站点，老用户的账号）的登录入口、找回密码、能力差异和两组连接线路，照现在代码里的实际行为画：`features/auth/AuthFlow.tsx`、`pages-account.tsx`、`registry/connection-routes.ts`（线路说明以 #1001 为准）。

## 并入正式规范时要处理的差异

- `03-layout-window.md` §1 的缩放下限写的是 0.7，要改成 0.9。
- `01-tokens.md` 和 `tokens.css` 的四套皮肤要减成两套（冻结层）。
- 个人中心在原型里是六个页签：订单并进「充值订阅」，用量看板并进「用量账单」，登录设备并进「账号安全」。现行的「异步任务」页原型没有画，要定放在哪。
- 账号安全页里开启、关闭两步验证和备用码，是原型新画的；现行代码只有登录时输验证码那一步，后台能不能支持要先核实。
- 「精选」里的创作者市场（上传作品、推荐、收益进余额）是新功能，后台还没有。
- 其余页面没有逐项对照完，并入时按 [24 旧新对照](../24-old-to-new-map.md) 再核一遍，原型漏画的现有能力不能删。
