# 21 · 页面模板（五种，新页面必选其一）

所有页面的内容区最宽 1000px（1280 设计宽减侧栏 216 减左右留白 64），在侧栏右侧居中；窗口更宽只是两边留白变多，窄了留白从 32 收到 16。高度随窗口滚动。上下相邻的卡片、提示框之间空 16。模板只规定骨架，具体内容看 `04`。

## T1 · 列表页（外接工具 / 技能 / 插件 / 备份 / 记录 / 反馈 / 登录设备）

```
PageHead  H1 + lead                                   [主按钮 primary]
Toolbar   [Segment 筛选] [SearchInput 240]            计数（等宽；没读到时不显示）
(可选)    快捷行：虚线胶囊「常用的一键加」
Card.list ListRow × N     （每行：图标 36 · 标题+副信息 · 附加动作 · 开关/按钮 · ···）
(可选)    分页（超过一页才出现，读不到时不出现）/ 「已限制为最近记录」提示
Empty     无数据 / 搜索无结果 两种（搜索无结果写「没有找到「词」」「换个词试试。」+「清除搜索」；只用了范围筛选时照旧「清空筛选」）
```
规则：主按钮永远在页头右侧；行内最多两个可见动作；批量操作不做（用户不需要）。

## T2 · 设置页（设置 / 个人中心各页签）

```
PageHead
SubNav（左 160）      分组内容（右）
  组 A ●               组标题 13/600
  组 B                 Card
  …                      SettingRow × N（左标题+说明，右控件）
```
规则：一次只展示一个分组（v3 决策）；每行即时生效 + toast；危险操作（清除 / 退出 / 回滚）放该组最后并红色。

## T3 · 详情抽屉页（记录详情 / 备份预览）

T1 的基础上，点击行从右侧滑出 `Drawer`（420px）：header 图标+标题+× / body 键值对 + 摘要卡 / footer 主按钮靠左。列表保持可见可点，切换行即切换抽屉内容；Esc 关抽屉。

## T4 · 向导页（首次引导 / 登录后准备 / 启动闪屏）

```
居中 Card 680px
  品牌小锁定（micro 28 + 字标 22）          第 N 步，共 M 步
  进度：编号圆点 + 名称，一行
  H2 步骤标题
  正文：说明 + 选项卡片 / 子步骤列表 / 结果 callout
  动作行：[上一步 ghost] ····· [主按钮] [稍后继续 ghost] [需要帮助 ghost]
```
规则：每步一个主按钮；失败留在当前步并给重试；可随时「稍后继续」回首页，进度保存。

## T5 · 双栏工作台（首页）

```
PageHead（状态式标题）                    [次要动作 × 1–2]
(可选) Banner 横幅（余额红 / Node 重启 / 引导提示）
左 1fr                         右 292px
  开始使用卡（未就绪时）          运行环境卡
  你的工具（ToolRow 列表）        账户余额卡
  试试第一条命令（没用过时）      可以试试 / 遇到问题卡
  最近卡
  还可以装（可折叠，记住收起）
```
规则：左栏是「要做的事」，右栏是「你的状态」；右栏卡片顺序固定；「还可以装」是推荐区，固定在左栏最下面，新卡片加在它上面或右栏底部，不插中间。「试试第一条命令」只给「最近」里还没有记录的工具。检测失败的工具留在「你的工具」里，不挪进「还可以装」（2026-10-04）。

## 通用外壳（所有模板共用，见 03）

顶栏（⌘K + 公告 + 帮助）→ 公告条（置顶未读时）→ 告警条（异常时）→ 内容 → 状态栏。任何模板都不得隐藏或改动外壳。

## 不允许的页面形态

- 全屏图表仪表盘（用 T5 的卡片装）
- 多级嵌套页签（最多一级页签 + 一级分段）
- 左右分栏 + 右栏再分栏
- 顶部横向大卡轮播
