# 给验收人的一页纸（v3.0.4）

**打开什么**：解压后双击「点这里开始.html」→ 主应用原型。顶部深色检阅条不是产品，是切换平台 / 主题 / 场景用的。

**这一版和上一版（我做的 v2）比，变了什么**

- 金额全部改成**美元**（后端 new-api 就是美元计价，v2 写 ¥ 是错的）。
- 工具配置多了「Claude 账号 / Google 账号」官方来源；密钥有四种状态和额度；订阅可以同时有多个；个人中心多了「用量看板」页签。
- 首次使用改成四步向导页：选开始方式 → 准备工具 → 确认连接 → 开始使用。第一步展示**全部工具**由用户自选，不偏向任何一方；注册后服务端自动建齐 4 把 Key，第三步自动写入。
- 多了 45 个组件的检阅页（`prototype/components.html`）。

**验收时看这几张图**（`prototype/previews/`）

1. 欢迎页：横版 Logo、四个工具胶囊、右下角客服二维码。
2. 登录后向导第 1 步：六个选项（五个工具 + 先聊天），没有「推荐」标签。
3. 向导第 2 步：Node.js →（Gemini 多一步 Python）→ 所选工具，Windows 是「一键安装」；第 3 步显示「Key 已自动写入」。
4. 首页老用户：工具列表六列对齐、右侧余额三色 + 「约还能用 N 天」。
5. 充值页：Stripe / 支付宝 / 微信支付图标。

**已拍板（2026-09-06）**

- 首次引导展示全部工具，用户自选，不偏向。
- 注册后服务端自动建齐 4 把 Key。

**这套东西以后怎么用**

- 替换旧界面：按 `24-old-to-new-map.md` 一项项对。
- 以后加功能、加按钮：按 `19-extension-playbook.md`，先改原型再改代码；改了什么记在 `CHANGELOG.md`。
- 哪些不能随便改：`23-governance.md` 的「冻结层」——颜色、字号、版式、模板、Logo 用法，改动要你书面确认。
- 你验收只看两样：PR 里的截图矩阵、`23 §3` 的完成定义勾选。

**给 Codex 的一句话**：以 v3.0.4 为基线，先读 `HANDOFF.md`，再读 `18-v3.0.2-restore.md` 了解本轮改动，按 `11-handoff-phases.md` 开工。
