## 开发

- 打码：密钥字段的值里带转义引号（`{"password":"abc\"defghij"}`、`password='abc\'def'`）时，
  原来停在转义引号处，后半段原样进运行日志、诊断导出、反馈导出和崩溃上报；现在按转义读到真正收尾的引号。
  只有收尾引号后面紧跟值的结尾、又不是下一个密钥字段的开引号时才这么读，否则照旧读到第一个引号，
  所以不带反斜杠的文本逐字不变，也不会因为一个不是转义的反斜杠（原样打出来的 Windows 路径）漏掉后一个字段。
  共用表 `redaction-patterns.ts` 新增 `QUOTED_SECRET_VALUE`，崩溃上报的字段规则改用它。
  #1888 随机输入测试发现；它那条「JSON 和单引号输出里的密钥字段」随机测试的值放开引号和反斜杠，按转义写进去再查。
