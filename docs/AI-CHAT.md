# AI聊天与生图

## 功能入口

主窗口工作台按“工具概览、AI聊天、会话管理、无限画布”排列。AI聊天复用当前已登录的星芒账号，renderer 只接收分组、模型、消息和本地图片资产标识，不接收 API Key 明文。

## 分组与密钥

- 打开页面后从账号服务读取可用分组。
- 切换分组时优先读取当前账号的本地加密 Key 缓存；缓存缺失时调用服务端复用或创建该分组 Key。
- Key 由 Electron `safeStorage` 加密保存，并按账号隔离。
- 同一账号、同一服务、同一分组的并发准备请求会合并，避免重复创建 Key。
- 在账号中心撤销或编辑 Key 后，对应的 AI聊天缓存会同步失效；缓存 Key 收到明确的 `401` 或服务端明确说明 Key/令牌无效的鉴权失败时也会自动移除，并复用或创建新的可用 Key。普通网络错误、IP 白名单和账号/分组权限类 `403` 不会误删缓存或创建新 Key。
- 生图分组只展示生产验证过的 `gpt-image-2`、`gpt-image-1` 和 `jimeng_high_aes_general_v21_L`，并优先选择 `gpt-image-2`。

## 接口与取消

- 文本模型调用 `https://xm.solov.cc/v1/chat/completions`，支持流式正文和思考内容。
- 文本请求有三道时限（`AI_CHAT_STREAM_LIMITS`）：等响应头 60 秒；开始接收后连续 3 分钟一个字节都没收到才停，思考内容和 SSE 注释保活都算收到；单次最长 30 分钟。超时停下时已收到的正文和思考过程保留在界面上，提示说清那是半截、可能已经计费。画布剧本解析（`completeOnce`）用同一套时限，但从不交回半截结果。
- 图片模型调用 `https://xm.solov.cc/v1/images/generations`。GPT Image 默认传 `quality: low`；即梦尺寸通过 `extra_fields` 传递且不传 `quality`。
- 生图属于非幂等请求。用户停止后，软件会停止等待和接收结果，但服务端可能已经开始生成并产生费用；界面会明确提示不要立即重复提交。
- 窗口关闭、账号登出和应用退出都会取消对应的文本与图片请求。迟到结果不会写回已失效的会话。

## 图片保存

图片生成成功后由主进程自动落盘：

- 开发环境：`<项目根目录>/output/user-<用户ID>/YYYY-MM-DD/`
- 安装环境：`<文档>/XingmangAI/user-<用户ID>/YYYY-MM-DD/`；「文档」被 OneDrive / iCloud 同步或拿不到时改用 `<用户主目录>/XingmangAI`（与新建项目文件夹同一套判断，`resolveStarterWorkspaceParent`）。历史账号再多一层 `realms/api-account`。

文件名为随机资产标识，不含提示词或账号凭据。这个目录是用户生成产物目录，清空聊天记录不会删除其中的图片；用户可自行归档或删除旧文件。

0.2.9 及以前存在 `<可执行文件所在目录>/output`：Windows 默认装在 Program Files 时写不进，Mac 上落在 .app 包里、更新即丢。启动时 `migrateLegacyAiOutput`（`ai-output-location.ts`）在后台把老位置里各 `user-<id>` 目录按原布局搬过来：同盘整目录改名（保留创建时间，作品库按它排序），跨盘逐个先复制成临时名再改名、复制完才删源文件；新位置已有的同名文件不覆盖，链接与非普通文件不跟随、原样留下。画布、聊天记录、视频任务只存作品编号（`xingmang-asset://<类型>/<编号>` 按编号在输出根下查找），所以布局不变就不需要改任何引用。Mac 上更新会整个换掉 .app，老包里的作品在新版本启动前就已经没了，搬不回来。

图片上右键会打开系统原生菜单，提供“复制图片”“图片另存为”和“在文件夹中显示”。菜单动作执行时会再次核对当前登录账号，避免账号切换后访问旧账号产物。

软件严格使用上述保存位置，不会在写入失败时静默改存其他位置。每次发出付费的生图、生视频请求之前，主进程先在当前账号的目录里真写一个随机名的小文件再删掉（`AiAssetStore.assertWritable`，`wx` 打开，不跟随预先放好的文件或链接）；写不进就不发请求，界面提示“保存位置写不进去，这次没有扣费”加下一步怎么办。续查已经付过费的视频任务不做这一步。启动时同样试写一次，失败记 `asset.output-directory.unavailable`，检查页的「AI 作品保存位置」一项每次运行都重新试写。

## 安全边界

- `Authorization`、API Key、上游原始错误体和远程图片 URL 不进入 renderer、聊天历史或运行日志。
- renderer 通过 `xingmang-asset://` 读取当前账号拥有的本地图片；主进程校验资产标识、账号所有权、文件类型和文件路径。
- 临时远程图片只允许公开 HTTPS 地址。每次重定向都会重新校验地址，并将连接固定到已验证的公网 IP，避免访问本机、私网或保留地址。
- 单张图片最大 64 MB；下载、响应和聊天历史都有独立大小与超时上限。
