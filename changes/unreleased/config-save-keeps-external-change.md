## 开发

- `electron/config-files-context.ts` 的 `executeFilePlans`：保存（含重置、修好它、开机那几处定点改写，经它写的二十来处都算）
  动手前记下每份目标的样子（整份字节的 SHA-256；原来不在的记「不在」），每次换上去、拿掉之前（等占用重试的每一次都算）
  再比一遍，变了就是别的程序刚存过：不盖它，整次放弃，报「配置文件刚被别的程序改过，为了不盖掉它的改动，这次没有保存，
  再试一次就好」。失败回滚也只动还是这次写进去的那份（原来不在的只删还是这次新建的那份，拿掉的只在原处仍空着时放回），
  别的程序换上去以后又存过的留着它的，算没能回滚，照旧报「部分文件无法自动回滚」，里面那条说明是哪个文件。以前这三种
  （保存覆盖、回滚覆盖、回滚删掉别人刚建的）都会把别人的改动盖掉（10-28 复核 O11、11-18 复核仍在、0.2.25 总单第 28 项）。
- 比内容不比修改时间：原样重存一遍不算冲突；同一个时钟刻里改了、大小也没变的照样认得出。文件被别的程序独占着读不了时，
  退一步比是不是同一个文件、大小和修改时间，照旧等一下再试，不因为读不了就提前失败。
