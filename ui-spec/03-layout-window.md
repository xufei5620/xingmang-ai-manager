# 03 · 窗口、导航与布局 v3.0

2026-09-14：日常导航增加「游戏加速」，顺序为首页、聊天、记录、画布、游戏加速。展开/折叠侧栏与命令面板共用页面注册表；固定 1280 DIP 五区布局不变。

2026-10-04：「更多」和「设置」钉在侧栏底部，展开状态记在本机；窗口逻辑高度不到 660 时导航行收到 32；收起侧栏时品牌标志兼作「展开侧栏」；账号卡两行；命令面板去掉标题行、框顶固定，设置里每一行单独可搜（§3）。

保持标题栏、侧栏、顶栏、内容区、状态栏五区和 1280 逻辑设计宽。平台控制、异常注入和屏幕预设只在窗口外的检阅控制条；用户设置不出现“模拟 Windows”或测试场景。

## 1. 窗口尺寸与缩放

首次无有效记录时，宽度取工作区宽 × 0.80 并限制在 960–1440，高度取工作区高 × 0.85 并限制在 560–900。工作区低于 1280×720 时优先最大化；小于最小目标 960×560 时按真实可用工作区处理，避免不可达窗口。1280×820 是设计/截图样例，不是固定默认窗口。

保存并恢复 bounds 与 maximized；保存位置已不在任何屏幕时回主屏可见区域。真实 Electron 与存储接入点按仓库约定实现，不能照本规范新建固定目录。

自动倍率 = clamp(内容区宽度 / 1280, 0.7, 1.25)；用户“自动 / 90% / 100% / 110%”对应乘数 1 / 0.9 / 1 / 1.1；最终倍率 = clamp(自动倍率 × 用户乘数, 0.7, 1.25)。内容区按 DIP 计算，系统 DPI 不再次手工乘入。“100%”是自动倍率的 1 倍，不保证最终 zoom 为 1。

最终 70/100/125% 属于测试注入，记录时注明跳过用户乘数。文字不能为防重叠无限缩小；最低倍率同时检查阅读与点击，不能只验几何无溢出。

## 2. 外壳与滚动

| 区域 | 规则 |
|---|---|
| 标题栏 | Windows/Linux 36px；macOS 为红黄绿与标题拖动留 46px |
| 侧栏 | 展开 216px / 折叠 60px，品牌图形和字标按 07 |
| 顶栏 | 46px；命令搜索、公告、帮助与客服；密集按钮可高 32px |
| 内容区 | padding 28×32，页面独立纵向滚动；页头标题、说明与该页动作 |
| 状态栏 | 30px；环境、来源、登录、USD 余额和版本，按钮可高 24px |

首页保留左侧工具与右侧摘要（292px）双栏。其余页面按既有单栏或页内二级导航组织；不重新设计成移动端卡片流。列内可柔性分配；表格宽内容由自身容器横向滚动，操作列与状态不能裁掉。

工具行基准为图标 40、名称 minmax(120,200)、状态 minmax(86,1fr)、来源/附加信息 72、主动作 92、更多 32px；具体复合行按共享变体调整。长名称省略并提供全文，状态最少 86px且可换行；窄宽优先压缩名称与说明，不隐藏关键动作。

Dialog 标准 480 / wide 640，Drawer 420；正文独立滚动，关闭和 footer 可达。产品 Drawer 避让顶栏 46和状态栏30；Notice 在状态栏上方16。浮层焦点与草稿见 [02](02-components.md)。

状态栏的网络位置显示真实探测的国家和 IP，可点击刷新。游戏加速连接成功、线路变化和确认停止后自动检测；过程中显示「正在检测网络位置…」，失败显示「网络位置未知」。停止未确认时保留原位置，不使用线路名称填造出口。按钮沿用状态栏 24px 密集控件规范，保留 `shell-network-location` 测试标记。

## 3. 分组导航

| 分组 | 入口 |
|---|---|
| 工作 | 首页、聊天、记录、画布（独立窗口标记） |
| 扩展 | 外接工具、技能、插件 |
| 帮助与维护 | 教程、检查；底部钉住：更多（安装卸载/备份/反馈/更新）、设置 |
| 账号区域 | 当前头像、身份、账户余额、充值、切换账号 |

分组使用分隔线；不添加重复说明标题。导航图标20、标签14、行36、gap10。当前页有文字与选中样式。检查问题与新版本角标只补充文字状态。

「更多」和「设置」不跟着滚：两项钉在导航底部（上方一条分隔线），展开时四个子页排在「更多」和「设置」之间。展开还是收起记在本机，下次打开照旧；打开四个子页中任何一页时自动展开。上面那段导航放不下时自己滚，上下边缘按滚动位置渐隐（20px），换页时把当前那一项滚进可视区（离边缘 16px）。窗口逻辑高度不到 660（按缩放折算后）时导航行 36→32、分组间距减半——这是固定 1280 版式下唯一的高度断点，只服务侧栏放得下。

折叠后保留全部入口的可访问名称与 Tooltip；顶上只留品牌标志，悬停或聚焦时换成「展开侧栏」按钮。账号区域仍能打开个人中心、切换账号和充值，不能压成无法操作的小点；折叠时不放余额刷新（展开侧栏和个人中心里都能刷新）。账号卡两行：头像 28、名字（历史账号后加小标签「历史账号」）、切换 ▾；金额加刷新、右边「充值」，有订阅时下面一行小字。恢复登录中头像位置是空白头像加转圈、金额位置是灰色占位条；余额没读到写「—」，悬停说明「余额暂时没有读到，点刷新再试」。侧栏导航独立滚动，账号区不会被长导航推出可视区。设置另有八项二级导航，一次只渲染一组面板，见 [04](04-pages.md)。

顶栏命令入口与 Ctrl/⌘ K 相同，灰字「搜功能、设置或教程…」；正常导航始终保留。命令面板是不带标题行的 640 宽 Dialog（标题只给读屏），框顶固定在窗口高度约 1/6 处，结果区最多约 8 行、多了在框里滚，输入时框不跳；输入框左侧放大镜，底部一行「↑↓ 选择　回车 打开　Esc 关闭」，Esc 一次就关（输入框里有字也一样）。结果按页面、个人中心、设置、教程分组；设置里每一行单独一条，写成「组名 › 行名」，选中后打开那一组、滚到那一行并亮一下（减少动画时只加一圈边框），这台电脑没有的行不出现。页级动作放页头或任务容器，不挤入顶栏。

## 4. 独立窗口与关闭

画布是独立窗口设计，默认目标1200×760并记住尺寸；本原型在页面内模拟。关闭画布仅结束该窗口，未保存修改及运行中任务按画布规则保护。付款展示目标480×720且受工作区约束；支付方式按真实 URL/POST 表单能力选择，关闭后订单仍可查询。启动闪屏显示当前阶段，主窗口就绪后结束。

关闭偏好保留询问、缩到托盘、直接退出。**无托盘时保留窗口和任务栏入口，只有明确选择直接退出才退出**；不能隐藏到无法找回的位置。macOS 将菜单栏与 Dock 表述清楚，具体原生行为由能力适配器确定。托盘菜单保留打开星芒、已装工具、充值、更新、设置、退出入口。

安装、保存、画布运行等未完成时，关闭先说明当前影响并提供继续等待/返回或实际可取消动作。只有真实完成后才提示已退出、已隐藏或已取消。二次启动与深链需要 show/focus 的设计通过原生接入验证，不由浏览器弹层代替。

## 5. 键盘与返回

| 输入 | 设计动作 |
|---|---|
| Ctrl/⌘ K | 打开命令面板 |
| Ctrl/⌘ , | 打开设置 |
| Ctrl/⌘ 1–5 | 按首页顺序打开工具；不可用时解释准备条件 |
| F11（Win/Linux）/ Control+⌘ F（Mac） | 当前窗口全屏，真实支持按平台验证 |
| Esc | 最上层浮层/引导关闭，遵守草稿保护 |
| Enter / Shift+Enter（聊天） | 发送 / 换行，中文组合输入中不发送 |
| /（有搜索的列表） | 非编辑上下文聚焦搜索 |

窗口关闭、退出快捷键遵循系统约定并处理进行中任务；不全局抢占输入框的 Ctrl/⌘ W/Q 等编辑行为。列表→详情→编辑→返回保留筛选、页码、选中项和滚动；帮助/检查跳往修复入口后保留“返回检查”路径。系统快捷键与原生菜单单独验收。
