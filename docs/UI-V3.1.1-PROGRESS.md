## 集成约定

- 控件 36/32/28，正文 14px；新增间距使用 `--ui-space-*`，避免覆盖旧 `--space-*` 的像素刻度。
- 默认皮肤 light=dawn、dark=obsidian；未选择皮肤时跟随当前主题的默认皮肤。
- 主按钮使用 `--accent-fg`，不能将旧 `--color-white` 改成动态值。
- 共享 CSS、App.tsx 与 IPC 三件套由集成负责人串行编辑。
- 原型模拟结果、品牌装饰状态和历史 QA 数字不当作真实服务证据。
- 本记录逐阶段更新；未完成项不标记完成。

## 当前集成说明

- 已引入 `ui-spec/reference/` 的18份设计参考与项目实施口径，原型脚本不进入产品。
- 独立 Electron 已按1440×900工作区策略运行并通过欢迎/登录冒烟；原生截图用于避免整体缩放后的CSS截图裁切。
- 新增主窗口退出状态请求与nonce回执；原生生命周期先检查任务，再等待画布保存关闭，最后持久化窗口位置。
- 多账号保存以实际HTTPS origin+userId标识；旧单会话文件保持兼容。旧续期/旧响应不能覆盖新账号。
- 公告使用已核实的 `/api/notice`，展示真实文本，按账号隔离已读状态，失败可重试。
- 系统通知默认关闭；仅更新可下载/已下载产生通知，按版本及阶段去重，点击聚焦主窗并打开更新页。`Notification.isSupported()`仅表示API能力。
- 外部 `xingmang://pay[/success]?order=...` 只打开当前账号订单查询，绝不确认到账；`xingmang://invite?code=...`只预填邀请码。参数白名单、单实例转发和冷启动暂存已接入，开发运行不覆盖已安装协议注册。
- 切账号时取消旧用户任务，候选读盘与网络验证均检查会话世代；同账号重登也使旧切换失效。
- 反馈报告预览ID绑定发送窗口与有效期，复制/导出固定快照；历史日志读取时再次脱敏。
